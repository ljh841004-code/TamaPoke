TamaPoke KO  v1.17-ko10.4  정리 (클로드 버전)
========================================
보드: Waveshare ESP32-S3-Touch-AMOLED-1.75
바탕: socquique/TamaPoke v1.17 + 기능 추가


[추가된 기능]
- 한국어 기본 : 처음 켜면 한국어 (시간 화면에서 언어 변경 가능)
- WiFi 시간 자동 맞춤 : 켤 때 + 하루 한 번 NTP 동기화 (기본 UTC+9)
                        끝나면 WiFi 자동 꺼짐 (배터리 절약)
- 야생 배틀 : 턴제 / 몸통박치기, 타입 기술, 방어, 도망 / 1세대 타입 상성
- 통신 대전 (2인) : 두 대를 ESP-NOW로 연결해 자동 대전 (공유기 필요 없음)
- 통신 교환 (2인) : 포켓몬 교환
                    윤겔라, 근육몬, 데구리, 고우스트는 교환하면 진화
- SD카드 소리 (ko2) : 배경음, 배틀 배경음, 포켓몬 울음소리
- ko4 : 큰 시계, 보관함, 도감 기록, 소리 설정, 훈련 3종, 실시간 저장,
        배틀 아이템(물약/포켓볼), 검정 글자 + 깔끔한 한글, 게이지 숫자


[ko10.4 : 체육관 / 오늘의 도전 / 사탕 / 진화 기술]
!! 통신 대전·교환은 양쪽 모두 ko10.4 여야 함 (통신에 시간 정보 추가)
- 배틀 메뉴   : [야생 배틀] [통신 2인] / [체육관 n/8] [오늘의 도전]
- 체육관      : 웅(산) 이슬(바닷가) 마티스(발전소) 민화(숲) 독수(늪) 초련(유적) 강연(화산) 비주기(사막)
                순서대로 도전, 관장 포켓몬 2~3마리 연속 (체력 이어짐), 도망·포켓볼 X, 물약 O
                이미 받은 배지는 재도전 가능 (배지 다시 안 줌)
- 지역 열기   : 처음 8곳 (초원 바닷가 숲 산 발전소 늪 꽃밭 도시) + 내 포켓몬 속성 지역
                배지 1 도장 / 2 묘지 / 3 설원 / 4 광산 / 5 유적 / 6 화산 / 7 사막 / 8 용의 계곡
- 오늘의 도전 : 날짜마다 지역 + 상대 3마리 (하루 동안 같음, 내 레벨보다 조금 높음)
                3연승 = 하루 1번 포켓볼·물약·사탕 +3 (다시 해도 되지만 보상 없음), 시계 필요
- 날씨 배틀   : 비 물x1.5 불x0.5 / 햇볕(여름 낮) 불x1.5 물x0.5 / 눈 얼음x1.5 (통신 대전 제외)
- 진화 기술   : 기본 -> 중간 -> 최종 (데미지는 그대로, 이름과 이펙트만)
                물대포->물의파동->하이드로펌프 / 불꽃세례->화염방사->불대문자 / 전기쇼크->10만볼트->번개
                덩굴채찍->잎날가르기->솔라빔 / 얼다바람->냉동빔->눈보라 / 박치기->누르기->파괴광선 등 16속성
                중간 = 기운 + 고리, 최종 = 광선 + 큰 폭발 + 화면 흔들림
- 사탕        : 이미 가진 포켓몬을 잡으면 [보관함 (사탕1)] / [사탕 3개로] (샤이니 +2, Lv30 이상 +1)
                20초 동안 안 고르면 보관함 / 보관함 가득 = 사탕만 / 보관함에서 놓아주기 = 사탕 1
                계열별로 모임 (파이리 사탕 = 파이리 리자드 리자몽), 최대 999
                스탯 카드 5쪽: 경험치(3) / 기분 기력 포만 +20(1) / 능력 편차 +2(5)
                               다음 알 샤이니 x4(10) / 진화 1레벨 빠르게(5, 실수 있을 때)
- 공놀이      : 공 3개 동시 낙하, 땅에 닿으면 기회 -1 (3번), 30초 / 보상은 그대로
- 날짜 설정   : 시간 설정 제목 아래 날짜 버튼 -> 월/일 모드 (12월->1월 넘기면 연도 +1)
- 통신 시간   : 배터리 방전으로 시간이 초기화된 쪽이 친구 다마포케의 시간을 자동으로 받음
                ("친구 다마포케에서 시간을 받았어요")
- 핫스팟      : 휴대폰 핫스팟을 WiFi 목록에 저장 -> 밖에서 필요할 때만 켜고 [지금 동기화] -> 끄기
                배터리 연결 상태면 전원을 꺼도 시계는 계속 감
- 보기 편하게 : 이름/상태 글자 테두리, 보관함 같은 포켓몬 모아서 + 같은 색 + x2
- 배경음      : 소리 설정에 bgm.wav 길이 표시. tamapoke-bgm.zip 의 mons/bgm.wav (2분 49초) 를
                SD mons 폴더에 덮어쓰기 (tools/prep_music.py 로 원곡 변환)
- 용량        : 2.75MB / 3MB


[ko10.3 : 공놀이 / 시간 화면]
- 공놀이 끊김 : 손가락을 대는 순간 공을 침 (전: 손을 뗄 때 판정 -> 늦거나 빗나감)
                2초 누르고 있기 = 그만두기는 그대로
- 공놀이 보상 : 최고 기록 넘기면 기분 + 기력 / 못 넘어도 1번 이상 치면 기력 +5
                (메인 화면 쓰다듬기로 기분 오르는 건 그대로)
- 시간 화면   : 시간 숫자 ~ 버전 글자까지 조금씩 위로 (버전 글자 안 잘리게)


[ko10.2 : 육성 속도 2배]
- 육성 레벨업 : 레벨 x 15분 (전: 30분)  1->2 15분, 2->3 30분, 3->4 45분 ...
                꼬부기 -> 어니부기(Lv.16) 30시간 / 거북왕(Lv.36) 약 6.6일 (실수 0회, 배틀 없이)
                미뇽 -> 망나뇽(Lv.55) 약 15.5일
- 배틀 경험치 : x 0.75 (야생 1승 = 육성 약 25분~1시간 15분어치, 통신 대전은 그 절반)
- 모든 포켓몬 적용. 지금 키우는 포켓몬도 레벨/경험치 그대로, 업데이트 후부터 빨라짐
- 진화 조건은 그대로: 레벨 + 게이지 모두 40 이상 + 깨어 있을 때 포켓몬 탭 / 실수 1회 = 진화 1레벨 늦음


[ko10.1 : 지역 / 날씨 / 계절]
- 2세대 SD카드 파일은 ko10 그대로 (새로 넣을 파일 없음). 통신은 ko10과도 됨
- 지역 고르기 : 야생 배틀 -> "어디로 갈까?" -> 8곳씩 2쪽 (옆으로 넘기기 또는 ◀ ▶)
                주황 테두리 = 내 포켓몬 지역 / [계속 만나기] = 같은 지역
                메인 화면 야생 알림 = 내 포켓몬 지역
- 지역 16곳   : 초원(노말) 바닷가(물) 숲(풀) 화산(불꽃) 산(바위) 설원(얼음)
                발전소(전기) 도장(격투) 늪(독) 사막(땅) 유적(에스퍼) 꽃밭(벌레)
                묘지(고스트) 용의 계곡(드래곤) 도시(악) 광산(강철)
- 출현 순서   : 1) 레어 (조건 맞을 때만. 전설 0.5% + Lv.40 이상 / 희귀 1%)
                2) 시간대 20% (새벽 6~10시, 밤 20~6시에만 나오는 포켓몬)
                3) 그 지역 속성 50%
                4) 공통 (구구 꼬렛 깨비참 꼬리선 캐터피 뿔충이 나옹 두두)
                예) 발전소 피카츄 약 8~11% (전: 0.9%), 내 Lv.20 이상이면 약 22%
- 레어 조건   : 라이코 발전소+비 / 썬더 발전소+낮 / 앤테이 화산+여름 햇볕 / 파이어 화산+여름
                스이쿤 바닷가+비 / 루기아 바닷가+밤 / 프리져 설원+눈
                칠색조 여름 햇볕+새벽 / 세레비 숲+벚꽃 / 뮤 유적+밤 / 뮤츠 광산+밤
                희귀 1%: 라프라스 잠만보 럭키 밀탱크 스라크 쁘사이저 헤라크로스 애버라스
                         프테라 무장조 폴리곤 메타몽 이브이 시라소몬 홍수몬 미뇽(계곡+비)
                레어 등장 = 금빛 반짝이 + 특별 효과음
- 배경 16종   : 메인 = 내 포켓몬 속성 / 야생 배틀 = 고른 지역 / 시간 따라 새벽 낮 노을 밤
- 날씨        : 비 (가끔, 3시간씩) / 눈 (12~2월만) / 쨍쨍한 햇볕 (6~8월 맑은 낮)
                벚꽃 (3~5월 가끔) / 낙엽 (9~11월 가끔) / 시계 안 맞으면 늘 맑음
- 날짜        : 큰 시계 위에 2026.09.25 (금)
- 공놀이      : 30초, 떨어뜨려도 3번까지 / 기록 갱신 = 기분+기력 (ko10.3: 못 넘어도 기력 +5)
- 배틀 후     : "다른 포켓몬을 계속 만날까요?" [계속 만나기] [나가기] (15초 뒤 자동 나가기)
- 시리얼      : WILD 6 -> 발전소에서 바로 야생 배틀 (0~15 = 지역 번호)
- 용량        : 2.72MB / 3MB

[ko9.1 변경]
- 훈련 그만두기 : 게임 중 2초 누르고 있기 (위쪽 터치로 꺼지던 문제 + 기록 미저장 수정)
- 훈련 선택     : 옆으로 넘기면 야생 배틀 / 통신 2인 페이지
- 야생 알림     : 30초 안에 안 누르면 사라짐 (전에는 5분)
- 울음소리      : 도감/보관함에서 포켓몬 누르면 울음소리, 그림 누르면 다시
                  (못 만난 검은 실루엣은 조용)

- 울음소리 도구 : tools/prep_cries.py (번호 WAV -> mons/cryNNN.wav, 16kHz 모노)


[ko9 새 기능]
- 좋아하는 음식 : 빨강/파랑/초록 열매 + 분홍 사탕 중 하나 (진화해도 그대로)
                  좋아하는 것 = 포만감 +35 / 알아내면 먹이 메뉴에 하트
- 육성 N일차   : 프로필의 나이 대신 1일차, 2일차 ...
- 프로필       : 포켓몬 그림 크게, 글씨 크게
- 배틀         : 상대 체력도 숫자로 (92/92)
- 레벨업       : 배틀 경험치 + 육성 시간 (레벨 x 30분 -> ko10.2부터 레벨 x 15분)
                 진행도에 "또는 육성 약 O시간 O분"
- 알림음       : 똥 / 게이지 30 이하 -> "딩동" 1번
                 (소리 켜짐 + 깨어 있음 + 화면 켜짐일 때만)
- 울음소리     : 피카츄, 이브이는 목소리 버전 (cry025.wav, cry133.wav 를 SD mons 폴더에)
                 울음소리는 SD카드 파일이라 펌웨어와 상관없이 언제든 바꿀 수 있음
                 형식: 16kHz 모노 16비트 WAV, 이름 cry001.wav ~ cry151.wav


[ko8 새 기능]
- 새로 시작   : 아래로 스와이프 -> 맨 아래 [새로 시작] -> 빨간 버튼 3초 누르기
                포켓몬, 도감, 보관함, 메달, 기록, 아이템 모두 삭제 -> 스타팅 선택부터
                WiFi, 소리, 언어 설정과 SD카드 파일은 남음
- WiFi 여러 개: 최대 5개 기억 (설정 페이지에서 추가, [삭제]로 지우기)
                켤 때 + 하루 한 번, 신호가 가장 센 저장된 WiFi로 시간 맞춤
- 개방 WiFi   : 저장된 WiFi가 안 되면 비밀번호 없는 WiFi로 시간만 받고 바로 끊음
                네트워크 화면 [개방 WiFi 켬/끔] 으로 선택
- QR코드      : [WiFi 설정하기] 화면의 큰 QR을 휴대폰 카메라로 찍으면 바로 연결
                WiFi 이름 / 비밀번호 tamapoke / 주소 192.168.4.1 큰 글씨
- 속도 훈련   : 볼이 시계 방향 8곳에서 무작위로 나옴 (같은 곳 연속 없음)
- 글꼴        : Noto Sans KR 부드러운 글꼴, 한글/영문/숫자 모두, 더 크게
- 한글 이름   : 천지인 키보드 (ㅣ ㆍ ㅡ / ㄱㅋ ㄴㄹ ㄷㅌ / ㅂㅍ ㅅㅎ ㅈㅊ / 띄움 ㅇㅁ 지움)
                같은 자음 연속은 [띄움] (각각), [ABC] = 영문, 최대 6글자
- 통신        : 대전/교환은 양쪽 기기 모두 ko8이어야 함 (한글 이름 때문에 형식 변경)
- 용량        : 2.68MB / 3MB


[ko7 새 기능]
- 경험치 레벨 : 배틀(이기기/잡기) + 시간(깨어 있고 게이지 40 이상, 1시간마다)
                최대 Lv.100 / 레벨 n = n^3 EXP / 진행도 카드에 EXP 막대
- 진화 레벨   : 3단계 = 기본형 -> 1차 진화 Lv.16, 최종 진화는 원작 레벨 (최소 20)
                2단계 = 원작 레벨 그대로 (피카츄 30, 이브이 30 ...)
- 레벨 초기화 : ko6에서 올리면 지금 포켓몬은 종류 그대로 Lv.1부터

[ko4 새 기능 요약]
- 큰 시계  : 기본 화면 하늘에 현재 시간 (HH:MM)
- 게이지   : 포만/기분/기력/청결 막대 안에 0~100 숫자
- 보관함   : 배틀 페이지 -> [보관함]. 잡은 포켓몬 + 이기면 20% (최대 60)
             최종 진화 후 작별하면 다음 포켓몬이 보관함에서 무작위로 나옴
             (보관함이 비었거나, 도망/놓아주기로 끝나면 알)
- 도감     : 옆으로 스와이프. 만난 포켓몬은 색으로, 탭하면 상세 정보
- 배틀     : 몸통박치기 / 타입기술 / 방어 / 물약 / 볼 / 도망
             물약 = 체력 절반 회복, 볼 = 포획 (체력 낮을수록 잘 잡힘)
             이기면 포켓볼 +2, 물약 +2 / 져도, 도망쳐도 불이익 없음
             시작 아이템: 포켓볼 5, 물약 2
- 훈련     : 포켓볼 버튼 또는 배틀 페이지 [훈련]
             공격 = 10초 연타 / 방어 = 떨어지는 볼 터치 (20초)
             속도 = 좌우에 잠깐 나오는 볼 터치 (15라운드) / 공놀이 = 기분만
- 소리 설정 : 아래로 스와이프 -> [소리] -> 배경음 / 포켓몬 목소리 / 시스템음
- 저장     : 1분마다 + 행동마다 + 전원 버튼 누를 때 (길게 눌러 끌 때도 저장)


[화면 조작]

- 위로 스와이프   : 스탯 카드 (옆으로 넘기면 배틀 / 메달 / 진행도)


[WiFi 시간 맞추기]
1. 아래로 스와이프 -> 가운데 [WiFi] 버튼
2. [WiFi 설정하기] -> 화면의 QR을 휴대폰 카메라로 찍기 (또는 TamaPoke-XXXX WiFi 연결,
   비밀번호: tamapoke)
3. 설정 페이지가 뜨면 집 WiFi 이름, 비밀번호, 시간대 입력 -> 저장
   (안 뜨면 브라우저에서 192.168.4.1)
4. 이후 자동으로 시간 맞춤
* 2.4GHz WiFi만 됨

        받은 포켓몬은 도감에 등록됨


[SD카드 소리] (ko2)
SD카드 /mons/ 폴더에 넣으면 자동 적용
  bgm.wav                 평소 배경음 (반복)
  battle_wild.wav         야생 배틀, 통신 대전 중 (결과 화면부터 평소 배경음)
  cry001.wav ~ cry151.wav 울음소리 (켤 때, 쓰다듬을 때, 종이 바뀔 때,
                          배틀 상대가 나올 때) / 번호 = 도감 번호 3자리
형식: WAV, 16kHz, 모노, 16비트 PCM (울음소리는 30초 이하)
변환: ffmpeg -i 원본.mp3 -ac 1 -ar 16000 -c:a pcm_s16le -map_metadata -1
      -fflags +bitexact -flags:a +bitexact cry025.wav
      (뒤쪽 옵션을 빼면 울음소리가 안 나옴)
없는 파일은 건너뛰고 기본 효과음은 그대로 나옴


[시리얼 명령] (115200bps, 디버깅용)
WIFI 이름|비번   WiFi 설정
WIFIOFF          WiFi 끄기
NTP              지금 시간 맞추기
TZ 540           시간대 (분 단위, 540 = 한국)
NET              네트워크 상태
WILD             바로 야생 배틀
ALERT            야생 출현 알림 띄우기
VOL 25 65 100    볼륨 (배경 울음 효과, 각 0~100) / VOL만 치면 현재 값
(원본 명령 STATS, HATCH, LVL 16 등도 동작)
