TamaPoke KO  v1.17-ko12.1  정리 (클로드 버전)
========================================
보드: Waveshare ESP32-S3-Touch-AMOLED-1.75
바탕: socquique/TamaPoke v1.17 + 기능 추가


[추가된 기능]
- 한국어 기본 : 처음 켜면 한국어 (설정 화면에서 언어 변경 가능)
- WiFi 시간 자동 맞춤 : 켤 때 + 하루 한 번 NTP 동기화 (기본 UTC+9)
                        끝나면 WiFi 자동 꺼짐 (배터리 절약)
- 야생 배틀 : 턴제 / 몸통박치기, 타입 기술, 방어, 도망 / 1세대 타입 상성
- 통신 대전 (2인) : 두 대를 ESP-NOW로 연결해 자동 대전 (공유기 필요 없음)
- 통신 교환 (2인) : 포켓몬 교환
                    윤겔라, 근육몬, 데구리, 고우스트는 교환하면 진화
- SD카드 소리 (ko2) : 배경음, 배틀 배경음, 포켓몬 울음소리
- ko4 : 큰 시계, 보관함, 도감 기록, 소리 설정, 훈련 3종, 실시간 저장,
        배틀 아이템(물약/포켓볼), 검정 글자 + 깔끔한 한글, 게이지 숫자


[ko12.1 : 전투 화면 두 코어]
- 설치       : 0xe000에 app 파일 하나 (세이브 유지) 또는 update.bin 으로 SD 업데이트
- SD카드     : 바꿀 것 없음
- 전투       : 화면 전송과 다음 장 그리기를 동시에 (버퍼 2개, 코어 2개)
- 확인       : 전투가 더 부드러운지, 이상한 깜박임/화면 섞임이 없는지
- 측정       : USB 로그 PERF bat 의 avg (전엔 약 90ms) 와 wait

[ko11.31 : 기술 4개, PP, 상태이상, 포켓몬센터]

- 기술 배우기: 5레벨마다(진화 때도) 새 기술 제안. 4개면 잊을 기술 고르기 / [배우지 않는다]
- 상태이상   : 독 화상 마비 잠듦 얼음 혼란 + 능력 올리기/내리기. 배틀 끝나면 풀림
- 포켓몬센터 : 야생 지역 선택 화면 아래. 30초 동안 PP 회복 (이기면 PP 가득, 지면 그대로)
- 도감       : 잡은 포켓몬 ○, 상세 화면 양옆 기술 버튼 4개 (배운 것만, 누르면 이펙트)
- 통신 대전  : 양쪽 모두 ko11.31 이상

[ko4 새 기능 요약]
- 큰 시계  : 기본 화면 하늘에 현재 시간 (HH:MM)
- 게이지   : 포만/기분/기력/청결 막대 안에 0~100 숫자
- 보관함   : 배틀 페이지 -> [보관함]. 잡은 포켓몬 + 이기면 20% (최대 60)
             최종 진화 후 작별하면 다음 포켓몬이 보관함에서 무작위로 나옴
             (보관함이 비었거나, 도망/놓아주기로 끝나면 알)
- 도감     : 옆으로 스와이프. 만난 포켓몬은 색으로, 탭하면 상세 정보
- 배틀     : 몸통박치기 / 타입기술 / 방어 / 물약 / 볼 / 도망
             물약 = 체력 절반 회복, 볼 = 포획 (체력 낮을수록 잘 잡힘)
             이기면 포켓볼 +2, 물약 +2 / 져도, 도망쳐도 불이익 없음
             시작 아이템: 포켓볼 5, 물약 2
- 훈련     : 포켓볼 버튼 또는 배틀 페이지 [훈련]
             공격 = 샌드백 연속 격파 (시간 안에 못 부수면 끝) / 방어 = 떨어지는 볼 터치 (3번 놓치면 끝)
             속도 = 주변에 잠깐 나오는 볼 터치 (15라운드, 빠를수록 점수) / 공놀이 = 기분만
- 소리 설정 : 아래로 스와이프 -> [소리] -> 배경음 / 포켓몬 목소리 / 시스템음
- 저장     : 1분마다 + 행동마다 + 전원 버튼 누를 때 (길게 눌러 끌 때도 저장)

[SD카드 소리] (ko2)
SD카드 /mons/ 폴더에 넣으면 자동 적용
  bgm.wav                 평소 배경음 (반복)
  battle_wild.wav         야생 배틀, 통신 대전 중 (결과 화면부터 평소 배경음)
  cry001.wav ~ cry151.wav 울음소리 (켤 때, 쓰다듬을 때, 종이 바뀔 때,
                          배틀 상대가 나올 때) / 번호 = 도감 번호 3자리
형식: WAV, 16kHz, 모노, 16비트 PCM (울음소리는 30초 이하)
변환: ffmpeg -i 원본.mp3 -ac 1 -ar 16000 -c:a pcm_s16le -map_metadata -1
      -fflags +bitexact -flags:a +bitexact cry025.wav
      (뒤쪽 옵션을 빼면 울음소리가 안 나옴)
없는 파일은 건너뛰고 기본 효과음은 그대로 나옴
