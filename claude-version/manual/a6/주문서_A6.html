5. 주문 전에 문의할 것 (게시판 / 전화)

A6는 규격 목록에 없고, 제본방향 안내에도 A6 크기가 나와 있지 않아요. 결제 전에 꼭 아래처럼 물어보세요.
안녕하세요. 소량 디지털 책자 주문 문의드립니다. - 크기: 비규격 105 x 148 mm (A6), 세로형 좌철, 중철 제본 - 쪽수: 표지 4쪽 + 본문 56쪽 (모두 60쪽), 표지/본문 모두 양면 칼라 - 파일: 도련 3mm 포함 작업사이즈 111 x 154 mm, CMYK 300dpi PDF 1. 이 크기로 중철 제본이 가능한가요? 2. 중철일 때 표지사이즈 칸에는 펼친 크기(210*148)를 넣는 게 맞나요, 한 쪽 크기(105*148)를 넣나요? 3. 파일은 60쪽 한 파일로 올려도 되나요, 표지(펼침 2면)와 본문(56쪽)을 나눠야 하나요? 4. 본문 56쪽 + 250g 표지 중철이면 안쪽 종이 밀림(크리프) 보정을 해 주시나요? 감사합니다.

답에 따라: 2번이 "한 쪽 크기"면 표지사이즈 105*148. 3번이 "나눠서"면 표지_펼침 + 본문_56쪽 파일을 올려요. 4번은 해 주면 좋고, 안 해 줘도 안쪽 바깥 여백이 1mm 이내로 줄어드는 정도라 괜찮아요.

6. 결제 직전 확인

  • 규격: 비규격 105*148 / 111*154 로 들어갔는지
  • 본문1 컬러 56페이지, 본문2 흑백 0페이지인지 (표지 4쪽은 따로 계산)
  • 제본: 중철, 세로형 좌철
  • 표지: 양면 칼라 · 단면무광코팅 · 오시 있음
  • 면지: 없음
  • 올린 파일 이름이 "인쇄용_" 으로 시작하는지
  • 견적 금액과 수량 확인 후 결제

7. 받은 뒤 확인

  • 쪽 순서: 1쪽 표지 → 2쪽 차례 → … → 60쪽 뒤표지
  • 재단: 글자가 잘린 곳 없는지 (특히 맨 위 색 띠의 제목, 아래 쪽 번호)
  • 색: 너무 진하거나 번진 곳 없는지
  • 문제가 있으면 사진을 찍어 바로 사이트에 문의

8. 참고

  • 펌웨어가 바뀌면 설명서도 새로 만들어 드려요. 같은 내용이 기기 SD의 manual.pdf(손바닥 가이드)에도 들어가요.
