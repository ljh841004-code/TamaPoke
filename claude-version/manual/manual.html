알림음 “딩동”

똥을 싸거나 게이지가 30 이하로 떨어지면 한 번 울려요 (소리 켬 · 깨어 있음 · 화면 켜짐일 때).

무게

사탕을 먹으면 늘고, 시간이 지나면 조금씩 빠져요. 무게 0 + 실수 0 + Lv.5 이상이면 “건강함” 메달.

유대감 (친밀도)

돌봐 줄 때마다 조금씩 올라가요 (먹이 +2, 놀기 +2, 쓰다듬기·목욕 +1). 돌봄 실수를 하면 1 내려가요. 스탯 카드 프로필에서 분홍 막대로 볼 수 있고, 100이면 “유대감 최대” 메달. 친밀도 70이 되어야 진화하는 포켓몬도 있어요 (14쪽).

기기가 꺼져 있던 시간도 흘러요. 다시 켜면 그동안 줄어든 만큼 반영되지만, 최대 2주까지만 계산하고 스탯이 15 아래로는 떨어지지 않아요.

레벨과 진화

경험치(EXP)로 레벨 업

레벨 n이 되려면 n³ EXP가 필요해요 (원작과 같은 방식, 최대 Lv.100). EXP를 얻는 방법은 세 가지예요.

방법얻는 양
배틀이기거나 잡으면 상대 종류 × 상대 레벨만큼 (통신 대전은 절반, 지면 0)

훈련다음 레벨 필요량의 5%, 최고 기록이면 20% + 사탕 1

예) 꼬부기 → 어니부기(Lv.16) 약 30시간, 거북왕(Lv.36) 약 6.6일 · 미뇽 → 망나뇽(Lv.55) 약 15.5일 (시간만으로 키울 때)

  • 3단계 포켓몬: 첫 진화 Lv.16, 최종 진화는 원작 레벨 (원작이 20 미만이면 20). 예) 파이리 16 → 리자드 36
  • 2단계 포켓몬: 원작 레벨 그대로. 예) 피카츄 30, 꼬렛 20
  • 돌봄 실수 1번마다 1레벨씩 늦어져요

  1. 레벨이 되고 네 게이지가 모두 40 이상이면 기본 화면에 빨간 진화! 버튼
  2. 누르면 “진화할까요?” → 진화 또는 형태 유지
  3. 진화하면 빛나는 연출과 울음소리. 기술도 더 강한 모습으로 바뀌어요 (22쪽)

통신 대전과 교환

다마포케 두 대가 가까이 있으면 WiFi 공유기 없이 직접 연결돼요 (ESP-NOW).

  1. 두 기기 모두 배틀 쪽 통신 2인 (또는 스탯 카드 2쪽)
  2. 둘 다 같은 메뉴를 눌러요: 대전 또는 교환
  3. 서로를 찾으면 자동으로 연결돼요

“다른 기기도 통신을 여세요” — 상대가 같은 화면을 열 때까지 기다려요. 위쪽 탭 = 닫기.

대전

지금 키우는 포켓몬끼리 자동으로 싸워요. 두 기기가 같은 배틀을 똑같이 계산해서 보여 줘요. 이기면 EXP (야생의 절반). 날씨 영향은 없어요.

교환

지금 키우는 포켓몬을 서로 바꿔요. 양쪽이 모두 확인해야 바뀌어요. 이름·능력 편차·훈련 기록·샤이니가 그대로 가요. 교환 진화 포켓몬은 여기서 진화할 수 있어요.

통신으로 시간 받기

배터리가 다 되어 시계가 초기화되었을 때, 시간이 맞는 친구 기기와 통신하면 시간을 자동으로 받아 와요.

통신은 두 기기의 펌웨어가 같은 통신 형식이어야 돼요 (ko10.4 이상끼리). 되도록 같은 버전으로 맞춰 주세요.

펌웨어 업데이트

새 기능이 담긴 펌웨어로 바꿔요. 두 방법 모두 포켓몬은 그대로 남아요.

A. SD카드로 (추천)

  1. PC Chrome에서 웹 설치 페이지 → Connect board → pick them manually로 update.bin 보내기 (SD카드 mons 폴더로 가요)
  2. 시간 설정 → WiFi → SD 업데이트 → 업데이트
  3. 진행 막대가 끝나면 자동으로 다시 켜져요

새 펌웨어를 예비 영역에 다 쓰고 검사가 끝난 뒤에만 바꿔요. 도중에 실패하면 원래 펌웨어 그대로예요.

현재 / 파일 버전

B. PC에서 esptool로

  1. Chrome/Edge에서 ESP Tool (esptool-js) → Baudrate 115200 → Connect
  2. 주소 0xe000에 tamapoke-ko-…-app-0xe000.bin → Program
  3. 끝나면 USB를 뽑고 PWR 6초로 껐다 켜기. 시간 설정 화면에 새 버전이 보이면 성공
Erase Flash는 누르지 마세요. 주소 0x0에 올리는 통합 이미지(…ko11.7.bin)는 저장 데이터를 초기화해요. 앱 파일은 0x10000이 아니라 꼭 0xe000에.

켜질 때 멈추면 — 부팅 진단과 안전 모드

  • 켜지다 멈춰 다시 시작되면 다음에 “last stop: 단계 이름”과 원인(CRASH, BROWNOUT…)을 보여 주고 4초 기다려요
  • 2번 연속 멈추면 안전 모드: SD카드·WiFi·소리 없이 켜요. 세이브는 건드리지 않아요
  • 정상으로 20초 넘게 돌면 기록이 지워져요
