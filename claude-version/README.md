# TamaPoke KO v1.17-ko12.10.3 (클로드 버전)

> 이 폴더는 **클로드(Claude) 버전**이에요. 저장소 루트의 TamaPoke v1.23과는 따로 관리하는 별도 갈래예요.
> v1.23의 어드벤처·컬렉션 기능은 이 버전에 없어요. (소리와 한글 글꼴은 옮겨 왔어요)

원본 [socquique/TamaPoke](https://github.com/socquique/TamaPoke) v1.17을 바탕으로
야생 배틀, 통신 대전/교환(ESP-NOW), WiFi 시간 자동 맞춤, 한국어 기본, SD카드 소리(배경음·배틀 배경음·울음소리),
보관함·도감·배틀 아이템·훈련 3종·소리 설정·실시간 저장·큰 시계·SD카드 업데이트,
경험치 레벨·타입별 기술 이펙트(ko7), 새로 시작·WiFi 여러 개·QR 연결·큰 글꼴·한글 이름(ko8)을 더했어요.
화면 모습은 `screenshots/` 폴더에 있어요 (PC 렌더러로 그린 실제 화면).

## SD카드에 파일 넣기 (울음소리, 배경음, update.bin)

1. 보드가 평소 화면인 상태에서 USB로 PC에 연결 (esptool 등 포트를 쓰는 창은 닫기)
2. Chrome에서 [웹 설치 페이지](https://socquique.github.io/TamaPoke/web/) → **2단계 Connect board** → 포트 선택
   (**Load sprites**는 누르지 않기: 스프라이트 40MB를 다시 받아요)
3. **pick them manually** → 파일 형식을 **"모든 파일 (\*.\*)"**로 바꾸고 파일 선택 → SD카드 `mons` 폴더에 저장돼요

| `fx/w001.bin`~`fx/w251.bin` (기술 이펙트, ko12.10부터) | 251 | 기술 종류별 기본 이펙트 |

- 다 들어갔는지: 설정 → SD 업데이트 → [SD 파일 하나로 묶기] → **[SD 파일 점검]** (시리얼 `SDCHECK`, PC는 `python3 TamaPoke/tools/sd_check.py <SD>`)
- 그림·이펙트·울음소리는 개인 사용 전용 파일이라 이 저장소에는 없어요. 덮어쓰기로만 넣어 주세요 (`mons` 폴더를 바꾸면 음악이 사라져요)

## 펌웨어 올리기

### A. SD카드로 (ko5.1부터, 추천)
1. 위 방법으로 `update.bin`을 보내요 (`mons/update.bin`이 돼요)
2. 아래로 스와이프 → WiFi → **[SD 업데이트]** → **[업데이트]**
3. 진행 막대가 끝나면 자동으로 다시 켜져요. 포켓몬은 그대로, 다 쓴 파일은 `update_done.bin`으로 바뀌어요
   (새 펌웨어를 예비 영역에 다 쓰고 검사가 끝난 뒤에만 바꿔요. 도중에 실패하면 기존 펌웨어 그대로)

### B. esptool로
1. Chrome/Edge에서 [ESP Tool (esptool-js)](https://espressif.github.io/esptool-js/) → Baudrate **115200** → Connect → 포트 선택
2. 주소 **`0xe000`**에 `tamapoke-ko-v1.17-ko12.10.3-app-0xe000.bin` → Program (**Erase Flash 누르지 않기**)
   (0x10000이 아니라 0xe000: SD 업데이트 뒤에도 esptool로 올린 펌웨어가 켜지게 부팅 선택 정보를 같이 써요.
   이 파일을 0x10000이나 0x0에 올리면 켜지지 않아요)
3. 처음 설치하거나 초기화하고 싶다면: 주소 `0x0`에 `tamapoke-ko-v1.17-ko12.10.3.bin`
4. 끝나면 USB를 뽑고 전원 버튼을 6초 눌러 껐다 켜기. 설정 화면(메인 위쪽 화살표) 아래쪽에 `v1.17-ko12.10.3`이 보이면 성공

### C. 와이파이로 (ko12.9.2부터)
1. 아래로 스와이프 → WiFi → WiFi 설정(QR 화면)
2. 휴대폰을 TamaPoke WiFi에 연결 (QR을 찍거나 비밀번호 입력)
3. 휴대폰 브라우저에서 `192.168.4.1/fw` → `update.bin` 고르고 [올리기]
4. 끝나면 저장하고 다시 켜져요. 포켓몬은 그대로. 0x0 통합 이미지는 받지 않아요

### D. 집 와이파이로 (ko12.9.4부터, 와이파이 없는 데스크톱도 OK)
데스크톱(랜선) ── 집 공유기 ── (와이파이) ── 다마포케. 다마포케에 집 와이파이가 저장돼 있어야 해요 (WiFi 설정하기에서 등록, 최대 5개).
1. 아래로 스와이프 → WiFi → 맨 아래 보라색 **[집 와이파이로 업데이트]**
2. 저장된 와이파이 중 가장 센 곳에 연결되면 화면에 주소가 크게 떠요 (예: `192.168.0.23/fw`)
3. 같은 공유기에 연결된 PC 브라우저 주소창에 그 주소를 그대로 입력 → `update.bin` 고르고 [올리기]
4. 끝나면 저장하고 다시 켜져요. 10분 동안 아무것도 안 하면 와이파이가 저절로 꺼져요
- 2.4GHz 와이파이만 돼요. 회사 와이파이는 기기끼리 접속을 막아 두는 경우가 있어서 안 될 수 있어요

> **ko3~ko5.1에서 ko6으로 올릴 때만** esptool이 바로 연결되지 않아요 (그 버전들의 USB 방식 때문).
> 장치 관리자에서 COM 번호 확인 → esptool 창을 닫고 PowerShell에서
> `$p = New-Object System.IO.Ports.SerialPort COM5,1200; $p.Open(); Start-Sleep 1; $p.Close()`
> → 화면이 꺼지면 esptool에서 Connect. **ko6부터는 원래 USB 방식이라 Connect만 누르면 돼요.**

> **켜지지 않을 때 (복구)**: esptool에서 파일 3개를 저장 영역을 건드리지 않고 올려요 —
> `0x0` 부트로더, `0x8000` 파티션 표, `0xe000` app 파일 (빌드 폴더의 `TamaPoke.ino.bootloader.bin`,
> `TamaPoke.ino.partitions.bin`, 또는 통합 이미지에서 잘라낸 것).

## 레벨과 진화 (ko7)

- 레벨은 **경험치(EXP)**로 올라요 (최대 **Lv.100**). 원작처럼 레벨 n이 되려면 n³ EXP.
  - **배틀**: 이기거나 잡으면 상대 종류 × 상대 레벨만큼 EXP (통신 대전은 절반, 지면 0)
  - **시간**: 깨어 있고 모든 게이지가 40 이상이면 1시간마다 레벨 1/4만큼
  - 진행도 카드(위로 스와이프 → 4쪽)에 파란 EXP 막대와 "다음 레벨까지 ○ EXP"
- **진화 레벨**: 3단계 포켓몬은 기본형 → 1차 진화 **Lv.16**, 최종 진화는 원작 레벨
  (예: 파이리 16 → 리자드 36, 미뇽 16 → 신뇽 55. 원작이 20 미만이면 20).
  2단계 포켓몬은 원작 레벨 그대로 (예: 피카츄 30, 꼬렛 20). 돌봄 실수 1번마다 1레벨 늦어져요
- 야생 포켓몬도 내 레벨 −4 ~ +1 (최대 100)
- **ko6 이하에서 올리면** 지금 포켓몬은 종류는 그대로, **Lv.1부터** 다시 시작해요.
  보관함에서 Lv.100이 넘던 포켓몬은 Lv.5가 돼요
- ko6의 Lv.338 원인: 저장 기록이 없을 때 WiFi 시간 맞춤이 "2026-01-01부터 꺼져 있었다"로 보고
  2주치 시간을 한꺼번에 더했어요. ko7에서 고쳤어요

## ko12.10.3: 전투 끊김 줄임

- 전투 끊김 줄임 (특히 도트): 매끈하게 만든 몬 그림을 프레임마다 저장해서 다시 사용 (애니메이션이 바뀔 때마다 멈칫하던 것)
- 그림자는 보이는 가장자리만 계산 (모든 화면 공통), 전투 배경은 0.15초마다 한 번만 새로 그림
- PC 측정: 전투 한 프레임의 계산량 약 절반

## ko12.10.2: 도트 크기·화질 / 기술 화면 새로 / 끊김·겹침 수정

- 전투 그림(도트) 크기 = 원작 크기: 포켓몬마다 원작 그림 높이에 맞춤 (뮤츠 우리 쪽 등 작게 나오던 것)
- 도트 화질: 매끈하게 키운 뒤 정확한 크기로 줄이고, 비슷한 색끼리 부드럽게 섞어 픽셀 계단을 줄임 (테두리는 그대로)
- 붐볼: 도트 모드에서도 원작 그림으로
- 전투 시작 끊김 줄임: 등장 연출 동안 SD 이펙트 읽기를 조금씩만
- 상태 카드 [기술] 쪽 새로: 기술 4개를 큰 글씨로 한 줄씩, [기술 바꾸기] → 배운 기술 목록(큰 글씨, 5개씩), 설명 창도 큰 글씨
- 기술머신·기억·장착 후 기본 화면에서 또 "배울까?" 묻던 것 고침 (4칸이 차 있으면 그 자리에서 칸 고르기)
- 도우미 고르기: 두 타입이면 "오늘 n/3"이 [유리]/[불리]에 가려지던 것
- 체육관 3쪽(챔피언 도전 포함) 아래 ▼ = 기본 화면으로

## ko12.10.1: 와이파이 SD 올리기 / 설명서 같이 업데이트 / 붐볼 얼굴

- 와이파이로 SD 파일 올리기: 펌 업데이트 주소의 /sd (예: 192.168.0.23/sd, 기기 와이파이면 192.168.4.1/sd) → 파일이나 폴더를 골라 SD mons 폴더에. 끝까지 받은 파일만 바뀌어요
- QR 설명서도 같이 업데이트: /fw 화면에서 update.bin과 manual.pdf를 같이 고르면 설명서도 새 버전으로 (마지막에 올린 설명서가 열려요)
- 펌 묶음에 설명서 2개 포함: manual.pdf(QR 설명서) + A6 인쇄용 설명서
- 설명서 내용 ko12.10 반영: Lv100, 원작 기술 251개, 기술머신, 기술 설명, 두 타입 상성, /sd 등

## ko12.10: 원작(크리스탈) 기술 체계

- 기술 251개 모두 원작(크리스탈) 그대로: 위력·명중·PP, 물리/특수는 속성으로, 부가효과·연속기·급소
- 특수 효과도 원작처럼: 방어, 공중날기·구멍파기, 솔라빔, 역린류, 맹독, 씨뿌리기, 대타출동, 날씨 기술, 리플렉터, 멸망의노래, 변신, 손가락흔들기 등
- 비행 타입 + 두 타입 + 2세대 상성 (4배 / 1/4배)
- 레벨 100 (전과 같은 시간에 100까지), 능력치 원작 공식, 진화 레벨 원작. 지금 Lv101~150은 Lv100으로
- 기술 배우기 원작 습득표. 예전 기술은 가장 비슷한 원작 기술로 자동으로 바뀜
- 전투 기술 창 새로 (속성·물리/특수/변화·PP 막대), 기술을 길게 누르면 설명
- 상태 카드 7쪽 [기술]: 배운 기술로 바꾸기, 놓친 기술은 사탕 3개로 기억
- 기술머신 57개 + 가방: 체육관 배지, 재대전 25%, 챔피언, 오늘의 도전, 탐험, 야생 승리(3/10/30%)
- 도감 상세 [기술표]: 레벨업 / 기술머신으로 배우는 기술
- 이펙트: 251개 기술 모두 SD 이펙트 (mons/fx/w001~w251.bin, SD에 새로 넣기)
- 전설·희귀: 진화·레벨업 때 금색/보라색 별 왕관, 전설 전용 기술 금색 테두리 + "전설의 기술"
- 희귀 포켓몬도 기본 화면에서 보라색 반짝임, 보관함 전설/희귀 금색·보라색 테두리 + 딱지
- 밸런스(시뮬): 일반 야생 ~70%, 희귀 ~61%, 전설 ~20%, 상성 유리 ~90% / 불리 ~43%, 체육관 20~50%
- 방 꾸미기 아래 안내문을 짧게 (둥근 화면 밖으로 넘치던 것)
- 통신 버전 8: 새 펌끼리만 통신 배틀·교환

## ko12.9.27: 기본 화면이 심심하지 않게 (전설 반짝임 / 물건으로 혼자 놀기 / 우산)

## ko12.9.5: 훈련 3가지 바꿈

- **공격: 번호 과녁** (예전 속도 "순서대로 터치"를 옮김): 1, 2, 3… 순서대로 과녁을 누르면 포켓몬이 속성 기술로 그 과녁을 쏴요.
  15라운드, 과녁 3→4→5개. 손가락이 옆 과녁에 닿는 실수는 **라운드마다 2번까지 괜찮아요**("앗! 다시 (실수 1/2)"), 3번째에 그 라운드 실패.
  맞힌 과녁 수 = 기록(공격 기록과 이어짐), 과녁 4개 ≈ 공격 훈련치 +1 (최대 +16)
- **속도: 몬스터볼 찾기**: 포켓몬이 빨간 빛을 타고 볼에 들어가고, 볼들이 자리를 바꿔요. 멈추면 4초 안에 포켓몬이 든 볼을 눌러요.
  10라운드, 볼 3→4→5개, 바꾸는 횟수·속도 점점 증가. 빨리 고를수록 점수(라운드당 최대 150, 합계 1500: 예전 속도 기록과 같은 크기)
- **놀이: 따라 해 봐! (기분)**: 포켓몬 둘레 버튼 4개(불꽃·물·풀·전기). 포켓몬이 보여 준 순서대로 누르기, 3개부터 하나씩 길어짐.
  하트 2개(틀리면 같은 순서 다시). 맞게 누른 횟수 = 점수, 보상·기록은 예전 공놀이와 같음
- 타이밍 펀치, 기울여 열매 모으기는 뺐어요

## ko12.9.3: 새 훈련 2개 · 터치/시계 오류 고침

- **공격 훈련 = 타이밍 펀치** (샌드백 대신): 빛이 가장자리를 돌고, 노란 칸에 올 때 탭하면 바위를 깨요. 주황 가운데 = "완벽!"(바위 2개).

- **공놀이 = 기울여 열매 모으기**: 처음 한 번 "오른쪽으로 / 아래쪽으로 기울이기"로 방향을 맞추고, 보드를 기울여 몬스터볼을 굴려
  30초 동안 열매(+1, 금색 +3)를 모아요. 구멍은 -5초. 보상·기록은 예전 공놀이와 같아요. 기울기 센서가 없으면 예전 공놀이
- **기분 막대 터치**: 막대보다 조금 위를 누르면 쓰다듬기(+5, 응석쟁이 +8)로 잡히던 문제 → 막대 위 18px까지 막대로
- **탐험 완료 알림**: 시계를 읽을 때 가끔 깨진 값(미래 시간)이 들어와 "탐험 완료"가 잘못 뜨던 문제 → 깨진 값은 버리고, 갑자기 튄 시간은 다음 읽기로 확인

## ko12.9.2: 와이파이로 펌웨어 올리기 · 사탕 메뉴 · 명예의 전당

- **와이파이 업데이트**: WiFi 설정 화면(QR)을 켜고 휴대폰을 TamaPoke WiFi에 연결 → 브라우저에서 `192.168.4.1/fw`
  → `update.bin` 고르고 [올리기]. 다 받고 검사가 끝난 뒤에만 바뀌고(도중에 끊기면 그대로), 0x0 통합 이미지는 거절,
  0xe000 파일은 받아요. 배터리 20% 미만(충전 중 아님)이면 시작 안 함. 끝나면 저장하고 다시 켜져요
- **사탕 카드**: 얇은 5줄 → 2열 큰 타일(2+2+1). 타일 사이를 눌러도 가까운 타일. "사용했어요!"는 위쪽 사탕 개수 자리에
- **명예의 전당**: 같은 포켓몬이 "능력 편차 올리기" 사탕을 쓴 뒤 우승하면 카드가 하나 더 생기던 문제 고침
- **능력 편차**: 사탕으로 올린 편차(최대 115)가 보관함에 넣었다 데려오거나 교환하면 110으로 깎이던 문제 고침
- **카드 합치기**: 이미 둘로 나뉜 카드는 명예의 전당 → 카드 상세 → [같은 포켓몬 카드 합치기] (같은 계열 카드가 있을 때만).
  확인 후 우승 횟수를 더하고, 최고 연승·첫 우승 날짜·최근 모습으로 1장만 남겨요

### 새 다마포케 보드에 처음 넣기
1. esptool-js(115200)로 주소 **`0x0`**에 `tamapoke-ko-v1.17-ko12.10.3.bin` 하나만 → Program
   (새 보드라 저장 데이터가 없어서 0x0 통합 이미지가 맞아요. Erase Flash는 필요 없어요)
2. SD카드: **FAT32**로 포맷(가능하면 할당 단위 **32KB**), 맨 위에 `mons.pak` 복사 (mons 폴더는 없어도 돼요)
   - exFAT은 읽지 못해요. 32GB보다 큰 카드는 보통 exFAT이라 FAT32로 다시 포맷해야 해요
   - 음악(bgm*.wav 등)은 선택: 넣으려면 SD에 `mons` 폴더를 만들고 그 안에 넣어요 (mons.pak과 같이 써요)
3. 켜면 첫 부팅 때 `mons.pak.map`(위치 지도)을 한 번 만들어요. 다음부터는 바로 켜져요
4. 설정 → SD 업데이트 → [SD 파일 하나로 묶기] → [SD 파일 점검]에서 모두 초록이면 끝

## ko12.8: 최종 점검판 (배틀 밸런스 · 엔딩 · SD 파일 묶기 · UI 정리)

- **배틀**: 파괴광선 같은 강한 기술은 상대를 쓰러뜨리면 반동 없음, 못 쓰러뜨리면 다음 턴에 **그 기술만** 쉬어요(버튼 회색 "쉬는 중").
  솔라빔·미래예지·섀도다이브는 반동 없음. 불꽃·물·전기·에스퍼 등 **특수 기술은 특수공격 vs 특수방어**로 계산(후딘·팬텀이 강해져요).
  막으면 "막아서 피해가 절반이 됐다!", 기술 버튼에 ▽(효과 별로)·✕(효과 없음). 같은 타입의 약한 기술 중복 정리.
  통신 대전은 두 기기 모두 ko12.8이어야 해요
- **엔딩**: 129계열을 모두 키우면(작별·놓아주기) 엔딩 → 왕관·칭호, 설정에 [엔딩 다시 보기].
  2회차 **반짝이는 여정**: 색이 다른 포켓몬 2배, 작별 5번마다 "원하는 알 고르기", 모두 반짝이로 키우면 두 번째 엔딩
- **알**: 뽑힌 등급을 다 키웠으면 위 등급으로. 도감 25종부터 알 12개 연속 전설이 없으면 다음은 전설
- **감기 약**: 두 번째 약은 3분 뒤 + "약 먹을 시간이에요!" 알림
- **SD**: 설정 → SD 업데이트 → [SD 파일 하나로 묶기] → **[SD 파일 점검]** (빠진 파일 확인). 원하면 [묶기 시작]으로
  `mons` 폴더 전체를 암호화된 `mons.pak` 하나로 (선택, 묶은 뒤 파일을 바꾸면 다시 묶기). 기술 이펙트 5개 추가 (171/171)
- **화면**: 둥근 화면 밖으로 잘리던 10곳 정리(연속 돌봄 🔥, 메달 카드, 기술 배우기 창 등), 설정 메뉴 순서 정리, 맨 아래 [새로 시작]
- 안정성: 오디오 스택 8KB, 49일 넘게 켜 둘 때 타이머 비교 수정, 물 체육관 난이도 조정. 시리얼 `SDCHECK`, `HEALTH`(남은 스택)

## ko12.6: 감기 · 친구 방문 · 생일 · PP

- **감기**: 청결 30 미만(똥이 쌓이면 더 잘)이나 포만 20 미만일 때 가끔 걸려요. 비 오는 날 산책해도 가끔.
  머리 옆 체온계 말풍선 → 포켓몬을 눌러 [약 먹이기] (1~2번, 30분 간격). 아픈 동안 기분이 더 떨어지고 시간 경험치 절반,
  2시간 동안 약을 안 주면 돌보기 실수 +1
- **친구 방문**: 8~21시에 가끔(하루 최대 3번) 보관함 포켓몬 1마리가 15분 놀러 와요. 누르면 같이 놀기(기분 +10, 친밀도 +1)
- **내 생일**: 설정 맨 아래 [내 생일]에서 월·일 설정. 그날은 기본 화면에 폭죽, 처음 볼 때 축하 화면 + 선물(기분 +30, 만능 사탕 1개, 1년에 1번)
- **PP**: 모든 기술 PP 2배 (예: 파괴광선 5 → 10). 지면 기술마다 PP가 최소 절반까지 차요
- 시리얼 테스트 명령: `SICK`, `VISIT`, `BDAY`

## ko12.5.1: 챔피언전 조정 · 질문 창

- **챔피언 레벨**: 내 레벨 +2~+6 → **+0~+4**
- **체육관·챔피언·오늘의 대전**: 상대 1마리를 쓰러뜨리면 싸우던 포켓몬이 **최대 체력 20%** 회복.
  교체해서 쉬는 포켓몬은 턴마다 **최대 체력 5%**씩 **절반까지** 회복
- **작별 / 진화 질문**: 위아래로 붙어 있던 버튼을 **좌우 큰 사각형 두 개**로. 사이를 누르면 아무것도 안 고름.
  [계속 함께] / [형태 유지]가 저장돼서 껐다 켜도 24시간(진화는 다음 레벨) 동안 다시 묻지 않아요
- 강한 기술 다음 턴 문장: "반동 때문에 움직일 수 없다!"

## ko12.5: 다마고치 2차 (훈육 · 하루 일과 · 성격)

- **게이지 터치**: 기본 화면의 포만/기분/기력/청결 막대를 누르면 +15 (청결은 똥도 1개 치움)
- **훈육**: 필요한 게 없는데도 가끔 떼를 써요 (빨간 !, "떼쓰는 중!", 15분). 포켓몬을 누르면 [혼내기] 훈육 +20·기분 -5 /
  [달래기] 기분 +5·훈육 -8. 무시하면 훈육 -3. 훈육이 높을수록 떼를 덜 쓰고, 60 이상이면 훈련 경험치 +25%
- **하루 일과**: 아침밥(6~11시) · 낮 놀이(12~19시) · 밤 재우기(20~24시 불 끄기). 셋 다 하면 기분 +10·친밀도 +3, 연속 일수 기록
- **성격**: 돌본 방식(30번 이상)으로 먹보·장난꾸러기·응석쟁이·노력파·깔끔이·의젓함 → 작은 효과. 리본 추억에도 표시
- **상태 카드 "생활" 쪽** (마지막 쪽): 성격, 훈육 막대, 오늘의 일과, 연속 기록
- **걸음**: 흔들 때 걸음이 오르던 문제 수정, 걸음 표시를 목표까지 차오르는 링으로 (시계 왼쪽)
- **배경 고르기**: 처음 한 번 [야외] / [방] 선택 창 (방 배경은 창문이 오른쪽, 왼쪽은 선반)

## ko12.4: 다마고치 기능 (추억 · 방 꾸미기 · 산책)

- **리본 추억**: 키우는 동안 태어난 날·진화 날짜·첫 승리·밥/간식/청소/쓰다듬기/놀이/훈련 횟수·승리 수를 기록하고,
  작별할 때 리본(명예의 전당)에 함께 남겨요. 리본 상세 → **[추억]** (2쪽). 이전에 받은 리본은 기록이 없어요.
  지금 키우는 아이는 업데이트한 날부터 기록돼요
- **방 꾸미기** (설정 → 방 꾸미기): 기본 화면 배경을 **야외 / 방**으로 바꿀 수 있어요. 방은 창문(시간·날씨에 따라 하늘이 바뀜),
  커튼, 액자, 나무 바닥, 러그. 잠들면 불이 꺼져요. 바닥 3자리(왼쪽·앞·오른쪽)에 물건을 놓아요:
  쿠션(처음부터), 화분(7일 연속 돌보기), 비치볼(공놀이 20점), 등불(1만 걸음 또는 야생 50승), 트로피(챔피언 1번), 곰인형(도감 100종)
- **산책** (설정 → 산책, 또는 기본 화면 왼쪽 위 발자국): 보드의 움직임 센서(QMI8658)로 걸음 수를 세요.
  하루 2,000걸음 기분 +20·친밀도 +2 / 5,000걸음 사탕 1개 / 10,000걸음 만능 사탕 조각 2. 최근 7일 그래프.
  흔들면 혼자 잠든 아이는 깨고, 깨어 있으면 신나해요. 센서가 없는 보드면 "움직임 센서를 찾지 못했어요"
- **부품 확인**: 켤 때 USB 로그에 `HW i2c: ...`, `HW imu=... mic=... codec=...` (시리얼 명령 `HW`)

## ko12.3.3: 검은 깜박임 수정

- 도감에서 처음 누른 기술(그리고 SD에서 이펙트를 읽는 중의 터치)에서 화면이 0.4초쯤 검게 깜박이던 문제의 진짜 원인:
  터치한 시각이 그 순간의 계산 기준보다 조금 늦으면 "마지막 터치 뒤 지난 시간"이 음수 → 아주 큰 수로 읽혀 "5분 동안 안 만짐"으로 판단,
  밝기를 8로 낮췄다가 다음 순간 되돌렸어요. 음수면 0으로 처리하도록 고쳤어요 (사용자 슬로모션 영상으로 찾음)

## ko12.3: 무지개구슬 · 도감 기술 그림

- **무지개구슬**: 구슬 합성이 성공했을 때 4% 확률로 나와요. **공격과 방어를 같은 %로 함께** 올려 줘요
  (키우는 포켓몬 속성, 장착 규칙은 일반 구슬과 같음). 무지개 테두리가 돌고 가운데 금별이 반짝여요.
  진화로 속성이 바뀌면 사탕 10개 + 30% 확률로 만능 사탕 1개 (일반 구슬: 사탕 3개 또는 10% 만능 사탕 1개)
- **도감 상세 기술 버튼**: `>` `+` 글자 대신 속성 그림 16종(불꽃·물방울·잎·번개…), 변화 기술은 반짝이
- **도감 첫 기술 깜박임**: 원작 이펙트를 아직 읽는 중이면 최대 1.5초 기다렸다가 원작으로 시작 (도트 이펙트가 잠깐 나오지 않음)

## ko12.2: 자동 잠자기 · 상대와 같은 수로 대전 · 깜박임 수정

- **자동 잠자기**: 기본 화면에서 3분 동안 아무것도 안 하면 스스로 잠들어요 (배부름 30 초과, 청결 30 이상일 때만).
  화면을 한 번 누르면 깨고, 자는 동안 배부름이 30까지 떨어지면 배고파서 스스로 깨요 (불 끄기로 재운 잠은 예전 그대로)
- **가출**: 배부름·기분·청결이 모두 0인 채로 **12시간** 방치되면 가출 준비가 돼요 (슬픈 버튼은 예전처럼 직접 누름)
- **체육관·챔피언·오늘의 대전**: 내 팀 수 = 상대 수 (펫 + 보관함 도우미, 최대 5마리). 상대 3마리면 도우미 2, 6마리면 도우미 5.
  보관함이 모자라면 있는 만큼만. **[혼자]** 버튼으로 펫 혼자 싸우기도 그대로 돼요. 교체 칸이 많으면 작은 버튼(그림·레벨·HP)
- **깜박임 수정**: 기술 이펙트가 도트 → 원작으로 도중에 바뀌던 것(시작할 때 정하고 끝까지 유지), 도감 상세의 첫 미리보기가 큰 그림과 크기·위치가 달라 튀던 것

## 사이트가 닫히면 (대처 방법)

웹 설치 페이지나 esptool-js 사이트가 없어져도 올릴 수 있어요:

1. **웹 설치 페이지를 내 PC에서 열기**: 이 저장소의 `TamaPoke/web/` 폴더에서
   `python -m http.server 8000` → Chrome에서 `http://localhost:8000` (Web Serial은 localhost에서도 돼요)
2. **Espressif Flash Download Tool** (Windows 프로그램, 인터넷 필요 없음): ESP32-S3 선택 →
   파일과 주소(위 표) 입력 → START
3. **esptool (파이썬)**: `pip install esptool` →
   `esptool --chip esp32s3 write-flash 0xe000 tamapoke-ko-v1.17-ko12.10.3-app-0xe000.bin`
4. **Arduino IDE**로 `TamaPoke/` 소스를 직접 올리기 (`TamaPoke/README_KO.md`의 설정 참고)
5. **SD카드에 파일 보내기**: SD카드를 빼서 PC에 꽂고 `mons` 폴더에 직접 복사하거나,
   `.bin` 파일(update.bin 등)은 `TamaPoke/tools/sdcard/mons/`에 두고
   `python TamaPoke/tools/send_sd.py --port COM5` (pyserial 필요)로 USB로 보내요
6. 켜지지 않을 때는 위 "복구" (파일 3개)

## 소리

SD카드 `mons` 폴더에 `bgm.wav`(평소), `battle_wild.wav`(배틀 중), `cry001.wav`~`cry151.wav`(울음소리).
형식은 **16kHz 모노 16비트 WAV**, 변환 방법은 `TamaPoke/README_KO.md`의 "SD카드 소리"를 보세요.

직접 구한 울음소리: 번호로 된 WAV 파일(`1.wav`, `025.wav`, `133 이브이.wav` …)이 있으면
`python TamaPoke/tools/prep_cries.py 받은폴더` → `sd_cries/mons/cry001.wav` …로 이름과 형식(16kHz 모노 16비트)을
맞춰 줘요 (Python만 있으면 돼요). 만들어진 `mons` 폴더를 SD카드에 복사하면 끝이에요.

최신 울음소리: `TamaPoke/tools/get_cries.py`를 실행하면 PokeAPI에서 1~151번의 최신 울음소리를 받아
`mons/cry001.wav`~`cry151.wav`로 변환해요 (Python + ffmpeg 필요). 게임 원본 음원(© Nintendo/Game Freak)이라
**개인용으로만** 쓰고 저장소에는 올리지 않아요.
