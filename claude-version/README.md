# TamaPoke KO v1.17-ko10.8 (클로드 버전)

> 이 폴더는 **클로드(Claude) 버전**이에요. 저장소 루트의 TamaPoke v1.23과는 따로 관리하는 별도 갈래예요.
> v1.23의 어드벤처·컬렉션 기능은 이 버전에 없어요. (소리와 한글 글꼴은 옮겨 왔어요)

원본 [socquique/TamaPoke](https://github.com/socquique/TamaPoke) v1.17을 바탕으로
야생 배틀, 통신 대전/교환(ESP-NOW), WiFi 시간 자동 맞춤, 한국어 기본, SD카드 소리(배경음·배틀 배경음·울음소리),
보관함·도감·배틀 아이템·훈련 3종·소리 설정·실시간 저장·큰 시계·SD카드 업데이트,
경험치 레벨·타입별 기술 이펙트(ko7), 새로 시작·WiFi 여러 개·QR 연결·큰 글꼴·한글 이름(ko8)을 더했어요.
화면 모습은 `screenshots/` 폴더에 있어요 (PC 렌더러로 그린 실제 화면).

## SD카드에 파일 넣기 (울음소리, 배경음, update.bin)

1. 보드가 평소 화면인 상태에서 USB로 PC에 연결 (esptool 등 포트를 쓰는 창은 닫기)
2. Chrome에서 [웹 설치 페이지](https://socquique.github.io/TamaPoke/web/) → **2단계 Connect board** → 포트 선택
   (**Load sprites**는 누르지 않기: 스프라이트 40MB를 다시 받아요)
3. **pick them manually** → 파일 형식을 **"모든 파일 (\*.\*)"**로 바꾸고 파일 선택 → SD카드 `mons` 폴더에 저장돼요

## 펌웨어 올리기

### A. SD카드로 (ko5.1부터, 추천)
1. 위 방법으로 `update.bin`을 보내요 (`mons/update.bin`이 돼요)
2. 아래로 스와이프 → WiFi → **[SD 업데이트]** → **[업데이트]**
3. 진행 막대가 끝나면 자동으로 다시 켜져요. 포켓몬은 그대로, 다 쓴 파일은 `update_done.bin`으로 바뀌어요
   (새 펌웨어를 예비 영역에 다 쓰고 검사가 끝난 뒤에만 바꿔요. 도중에 실패하면 기존 펌웨어 그대로)

### B. esptool로
1. Chrome/Edge에서 [ESP Tool (esptool-js)](https://espressif.github.io/esptool-js/) → Baudrate **115200** → Connect → 포트 선택
2. 주소 **`0xe000`**에 `tamapoke-ko-v1.17-ko10.8-app-0xe000.bin` → Program (**Erase Flash 누르지 않기**)
   (0x10000이 아니라 0xe000: SD 업데이트 뒤에도 esptool로 올린 펌웨어가 켜지게 부팅 선택 정보를 같이 써요.
   이 파일을 0x10000이나 0x0에 올리면 켜지지 않아요)
3. 처음 설치하거나 초기화하고 싶다면: 주소 `0x0`에 `tamapoke-ko-v1.17-ko10.8.bin`
4. 끝나면 USB를 뽑고 전원 버튼을 6초 눌러 껐다 켜기. 시계 화면 아래쪽에 `v1.17-ko10.8`이 보이면 성공

> **ko3~ko5.1에서 ko6으로 올릴 때만** esptool이 바로 연결되지 않아요 (그 버전들의 USB 방식 때문).
> 장치 관리자에서 COM 번호 확인 → esptool 창을 닫고 PowerShell에서
> `$p = New-Object System.IO.Ports.SerialPort COM5,1200; $p.Open(); Start-Sleep 1; $p.Close()`
> → 화면이 꺼지면 esptool에서 Connect. **ko6부터는 원래 USB 방식이라 Connect만 누르면 돼요.**

> **켜지지 않을 때 (복구)**: esptool에서 파일 3개를 저장 영역을 건드리지 않고 올려요 —
> `0x0` 부트로더, `0x8000` 파티션 표, `0xe000` app 파일 (빌드 폴더의 `TamaPoke.ino.bootloader.bin`,
> `TamaPoke.ino.partitions.bin`, 또는 통합 이미지에서 잘라낸 것).

## 레벨과 진화 (ko7)

- 레벨은 **경험치(EXP)**로 올라요 (최대 **Lv.100**). 원작처럼 레벨 n이 되려면 n³ EXP.
  - **배틀**: 이기거나 잡으면 상대 종류 × 상대 레벨만큼 EXP (통신 대전은 절반, 지면 0)
  - **시간**: 깨어 있고 모든 게이지가 40 이상이면 1시간마다 레벨 1/4만큼
  - 진행도 카드(위로 스와이프 → 4쪽)에 파란 EXP 막대와 "다음 레벨까지 ○ EXP"
- **진화 레벨**: 3단계 포켓몬은 기본형 → 1차 진화 **Lv.16**, 최종 진화는 원작 레벨
  (예: 파이리 16 → 리자드 36, 미뇽 16 → 신뇽 55. 원작이 20 미만이면 20).
  2단계 포켓몬은 원작 레벨 그대로 (예: 피카츄 30, 꼬렛 20). 돌봄 실수 1번마다 1레벨 늦어져요
- 야생 포켓몬도 내 레벨 −4 ~ +1 (최대 100)
- **ko6 이하에서 올리면** 지금 포켓몬은 종류는 그대로, **Lv.1부터** 다시 시작해요.
  보관함에서 Lv.100이 넘던 포켓몬은 Lv.5가 돼요
- ko6의 Lv.338 원인: 저장 기록이 없을 때 WiFi 시간 맞춤이 "2026-01-01부터 꺼져 있었다"로 보고
  2주치 시간을 한꺼번에 더했어요. ko7에서 고쳤어요

## ko10.8: 기본 화면 행동, 새 포켓몬 동작(SD), 빠른 터치

- **빠른 연타 인식**: 터치를 화면 그리기와 따로(8ms마다) 읽어요. 예전에는 그리는 동안(85ms 중 70ms) 못 읽어서
  빠르게 연타하면 뗐다 누른 게 한 번으로 합쳐졌어요 (공격 훈련 4번째 샌드백부터 안 세지던 원인).
  방어·속도·공놀이·일반 탭도 같이 좋아져요
- **천천히 끄는 드래그도 인식**: 밑에서 위로(스탯 카드) 같은 느린 드래그가 한 번의 탭으로 처리되던 문제 수정.
  1.5초까지 끌어도 되고, 조금 비스듬해도 주된 방향으로 인식해요
- **기본 화면 행동** (기분 좋을 때 무작위로):
  - **속성 기술 연습**: 기 모으기 → 발사/공격 + 배틀과 같은 속성 이펙트 (진화 단계별 기술)
  - **심심해**: 3분 넘게 안 놀아주고 기분 70 미만이면 빙글빙글 구르거나 드러누워 "심심해..."
  - **필요한 것 말하기**: 스탯이 45 미만이면 "배고파" / "씻고 싶어" / "심심해..." / "Zzz"
  - **밤 (22~6시)**: 꾸벅꾸벅 "Zzz"
  - **날씨**: 비 = 몸 털기 + 물방울, 눈 = 떨기 "추워", 햇볕 = 드러누워 일광욕
  - **신남** (기분 80 이상): 포즈 + 음표
  - **쓰다듬기** (포켓몬 탭): 포즈·끄덕임, 가끔 빙글 돌기 + 음표
- **SD카드 포켓몬 그림 새로 만듦** (`tamapoke-ko10.8-sprites.zip`, 502개, 압축 풀면 95MB):
  새 동작 4개 추가 — 구르기(전부), 기 모으기(전부), 발사(492개), 드러눕기(118개).
  없는 동작은 비슷한 동작으로 대신해요. SD카드 `mons` 폴더의 `p001.bin`~`p251.bin`, `ps001.bin`~`ps251.bin`을 **덮어쓰기**
  - 새 그림은 **예전 펌웨어에서도 그대로 읽혀요** (새 동작만 무시). 예전 그림도 새 펌웨어에서 읽혀요 (새 동작만 없음)
  - 카드 리더기로 PC에서 복사하는 게 가장 빨라요. 웹 설치 페이지로는 95MB라 25분쯤 걸려요
- 모습: `screenshots/60_beh_skill.png` ~ `65_beh_sun.png`

## ko10.7: 공격 훈련 버티기, 훈련 보상

- **공격 훈련**: 10초 연타 대신 **샌드백 연속 격파**. 제한 시간 안에 부수면 다음 샌드백, 못 부수면 끝.
  샌드백마다 필요한 타격 6 → 7 → 8…, 제한 시간 4초에서 0.06초씩 줄어요 (최소 2초).
  화면: 큰 숫자 = 부순 개수, 빨간 막대 = 남은 체력, 초록 막대 = 남은 시간. 결과에 총 타격 수
  - 공격 상승량은 그대로 (총 타격 4번 = 1, 최대 18). **공격 최고 기록은 부순 샌드백 수로 0부터 다시**
- **훈련 보상** (공격·방어·속도): 1점 이상이면 경험치 **다음 레벨 필요량의 5%**,
  **최고 기록 갱신**이면 **20% + 키우는 계열 사탕 1개**. 결과 화면 맨 아래 초록 글씨로 표시
  (능력치 상승·기분 +6은 그대로. 훈련마다 기력 -12라 연속 약 8번까지. Lv.100이면 사탕만)
- 모습: `screenshots/25_sack.png`, `screenshots/25b_sack_result.png`

## ko10.6: 실수 회복, 방어·속도 훈련 기록 갱신

- **실수 회복**: 모든 스탯을 **40 이상으로 12시간 연속** 유지하면 방어 +1과 함께 **실수 -1**
  (12시간 방어 보너스와 같은 타이머. 잠자는 동안은 멈춤, 40 아래로 떨어지면 처음부터. 꺼도 저장돼요)
  - 진행도 카드(스탯 카드 4쪽)에 "실수 회복까지 7시간 12분" 표시. 스탯이 40 아래면 조건 안내
  - 사탕 5개로 실수 1개 지우기도 그대로
- **방어 훈련**: 20초 제한 대신 **3번 놓치면 끝** (공놀이처럼 목숨 3개). 시간이 갈수록 더 빨리·더 자주 떨어져요.
  예전에는 20초에 최대 28개라 기록을 넘을 수 없었어요. 방어 상승량은 그대로 (막은 볼 2개 = 1, 한 번에 최대 18)
- **속도 훈련**: 15라운드 그대로, 맞히면 **빨리 누를수록 점수** (100 - 반응시간/10, 0.25초 = 75점, 최소 10점).
  합계 최대 1500점. 결과에 "맞힘 15/15 평균 0.30초" 표시. 속도 상승량은 그대로 (맞힌 횟수)
  - 점수 단위가 바뀌어 **속도 최고 기록은 0부터 다시** (방어·공격·공놀이 기록은 그대로)
- 모습: `screenshots/05_train_defense.png`, `screenshots/07b_train_speed_result.png`, `screenshots/03g_card_mistakes.png`

## ko10.4: 체육관·오늘의 도전·사탕·진화 기술

⚠️ **통신 대전·교환은 양쪽 모두 ko10.4**여야 해요 (통신에 시간 정보가 추가됨).

- **체육관 배지 8개** (배틀 페이지 → 체육관): 웅(산) → 이슬(바닷가) → 마티스(발전소) → 민화(숲) →
  독수(늪) → 초련(유적) → 강연(화산) → 비주기(사막). 관장 포켓몬 2~3마리 연속, 도망·포켓볼 불가, 물약 가능.
  **배지 1개마다 지역 1곳이 열려요** (처음 8곳 열림, 내 포켓몬 속성 지역은 항상 열림):
  도장 → 묘지 → 설원 → 광산 → 유적 → 화산 → 사막 → 용의 계곡
- **오늘의 도전**: 날짜마다 지역 1곳 + 상대 3마리(하루 동안 같음). 3연승하면 하루 1번 포켓볼·물약·사탕 +3
- **날씨가 배틀에 영향**: 비 = 물 ×1.5·불 ×0.5 / 햇볕 = 불 ×1.5·물 ×0.5 / 눈 = 얼음 ×1.5 (통신 대전은 제외)
- **진화 단계별 기술**: 기본 → 중간 → 최종 (예: 물대포 → 물의파동 → 하이드로펌프). 중간은 기운·고리,
  최종은 광선·큰 폭발·화면 흔들림. 데미지는 그대로
- **사탕**: 이미 가진 포켓몬을 잡으면 [보관함 (사탕 1)] / [사탕 3개로] 선택 (샤이니 +2, Lv30↑ +1).
  보관함에서 놓아주기 = 사탕 1. 스탯 카드 5쪽에서 사용: 경험치(3), 기분·기력·포만 +20(1),
  능력 편차 +2(5), 다음 알 샤이니 ×4(10), 진화 1레벨 빠르게(5)
- **공놀이**: 공 3개가 동시에 떨어짐, 땅에 닿으면 기회 −1 (3번), 30초
- **시간**: 시간 설정에 **날짜(월·일)** 버튼. 배터리가 방전돼 시간이 초기화되면 **시간이 맞는 친구와 통신할 때
  자동으로 시간을 받아요**
- **보기 편하게**: 포켓몬 이름·상태 글자 테두리, 보관함에서 같은 포켓몬은 **모아서 나열 + 같은 색 + x2**
- **배경음**: 소리 설정에 bgm.wav 길이 표시 (0분 30초면 파일이 잘린 것). `tools/prep_music.py`로 원곡을
  자르지 않고 16kHz 모노로 변환
- 모습: `screenshots/37`~`43`

## ko10.3: 공놀이 개선, 시간 화면

- **공놀이 끊김 수정**: 손가락을 **대는 순간** 공을 칩니다 (전에는 손을 뗄 때 판정해서 공이 이미 지나가
  늦거나 빗나갔어요). 2초 누르고 있으면 그만두기는 그대로
- **공놀이 보상**: 최고 기록을 넘으면 **기분 + 기력**, 못 넘어도 1번 이상 치면 **기력 +5**
- **시간 설정 화면**: 시간 숫자부터 아래 버튼·버전 글자까지 조금씩 위로 (버전 글자가 가장자리에 잘리지 않게)

## ko10.2: 육성 속도 2배

- **육성 시간 레벨업: 레벨 × 15분** (전에는 30분). 1→2 15분, 2→3 30분, 3→4 45분 …
  - 예) 꼬부기: 어니부기(Lv.16) 30시간, 거북왕(Lv.36) 약 6.6일 (전: 2.5일 / 13일)
  - 미뇽 → 망나뇽(Lv.55) 약 15.5일 (전: 약 31일)
- **배틀 경험치 × 0.75** (야생에서 한 번 이기면 육성 약 25분~1시간 15분어치. 통신 대전은 그 절반)
- 모든 포켓몬에 똑같이 적용돼요. 지금 키우는 포켓몬도 레벨·경험치는 그대로, 업데이트한 뒤부터 빨라져요

## ko10.1: 지역·날씨·계절

2세대 SD카드 파일은 ko10 그대로 쓰면 돼요 (새로 넣을 파일 없음). 통신은 ko10과도 돼요.

- **지역 고르기**: 야생 배틀을 누르면 **"어디로 갈까?"** 화면이 나와요. 한 쪽에 8곳씩 2쪽
  (옆으로 넘기거나 ◀ ▶ 누르기). 주황 테두리 = 내 포켓몬 속성의 지역.
  [계속 만나기]는 같은 지역에서 다음 포켓몬, 메인 화면의 야생 알림은 내 포켓몬 지역이에요
- **지역 16곳 = 속성 16개**: 초원(노말) 바닷가(물) 숲(풀) 화산(불꽃) 산(바위) 설원(얼음) 발전소(전기)
  도장(격투) 늪(독) 사막(땅) 유적(에스퍼) 꽃밭(벌레) 묘지(고스트) 용의 계곡(드래곤) 도시(악) 광산(강철)
- **출현 순서**: ① 레어(조건이 맞을 때만, 전설 0.5%·Lv.40부터 / 희귀 1%) → ② 시간대 20%
  (새벽 6~10시, 밤 20~6시에만 나오는 포켓몬) → ③ 그 지역 속성 50% → ④ 어디서나 나오는 공통
  (구구, 꼬렛, 깨비참, 꼬리선, 캐터피, 뿔충이, 나옹, 두두)
  - 예: 발전소에서 피카츄 한 판에 약 8~11% (전에는 어디서나 0.9%), 내 레벨 20 이상이면
    피츄가 피카츄로 나와서 약 22%
- **레어 조건**: 라이코(발전소+비) 썬더(발전소+낮) 앤테이(화산+여름 햇볕) 파이어(화산+여름)
  스이쿤(바닷가+비) 루기아(바닷가+밤) 프리져(설원+눈) 칠색조(여름 햇볕+새벽) 세레비(숲+벚꽃)
  뮤(유적+밤) 뮤츠(광산+밤) / 라프라스·잠만보·럭키·스라크·헤라크로스·애버라스·무장조 등 1%.
  레어는 금빛 반짝이와 특별 효과음으로 나와요
- **배경 16종**: 기본 화면은 내 포켓몬 속성, 야생 배틀은 고른 지역 (시간에 따라 새벽·낮·노을·밤)
- **날씨 (WiFi로 받은 날짜)**: 비(가끔, 5분마다 바뀜) / 눈(12~2월만) / 쨍쨍한 햇볕(6~8월 맑은 낮) /
  벚꽃(3~5월 가끔) / 낙엽(9~11월 가끔). 시계가 안 맞으면 늘 맑음
- **날짜**: 큰 시계 위에 `2026.09.25 (금)`
- **공놀이**: 30초 동안, 공을 떨어뜨려도 3번까지 다시. **최고 기록을 넘을 때만** 기분·기력 상승
  (메인 화면 쓰다듬기는 그대로)
- **야생 배틀 후**: "다른 포켓몬을 계속 만날까요?" [계속 만나기] / [나가기] (15초 뒤 자동으로 나가기)

## ko8 새 기능

- **새로 시작**: 아래로 스와이프(시간 설정) → 맨 아래 **[새로 시작]** → 빨간 버튼을 **3초 동안 누르고 있기**.
  포켓몬·도감·보관함·메달·기록·아이템이 모두 지워지고 파이리/꼬부기/이상해씨 선택부터 다시 시작해요.
  **WiFi·소리·언어 설정은 남아요**. SD카드 파일(울음소리, 배경음)도 그대로예요
- **WiFi 여러 개 + 개방 WiFi**: WiFi를 **최대 5개**까지 기억해요 (WiFi 설정 페이지에서 추가할 때마다 저장,
  목록에서 [삭제]). 켤 때와 하루 한 번, 주변을 검색해서 **신호가 가장 센 저장된 WiFi**로 시간을 맞춰요.
  저장된 WiFi가 안 되면 **비밀번호 없는 WiFi**에 잠깐 연결해 시간만 받고 바로 끊어요
  (네트워크 화면 [개방 WiFi 켬/끔]으로 끌 수 있어요. 로그인 페이지가 있는 공용 WiFi는 시간을 못 받으면 다음 WiFi로 넘어가요)
- **WiFi 설정 화면**: 큰 **QR코드** → 휴대폰 카메라로 찍으면 비밀번호 입력 없이 TamaPoke WiFi에 연결돼요.
  WiFi 이름·비밀번호·주소(192.168.4.1)도 큰 글씨로 보여요
- **속도 훈련**: 볼이 좌우 2곳이 아니라 **시계 방향 8곳**(12시, 1시 반, 3시 …)에서 무작위로 나와요
- **글꼴**: 한글과 영문·숫자 모두 **Noto Sans KR** 부드러운 글꼴(가장자리 매끄럽게), 크기도 커졌어요
  (본문 16→20px, 제목 20→26px, 큰 글씨 36px)
- **한글 이름**: 이름 바꾸기(위로 스와이프 → 이름 탭)에서 **천지인 키보드**(ㅣ ㆍ ㅡ, ㄱㅋ …).
  같은 자음을 연달아 쓰려면 [띄움] (예: 각각 = ㄱ ㅣ ㆍ ㄱ [띄움] ㄱ ㅣ ㆍ ㄱ). [ABC]로 영문 키보드. 최대 6글자
  - 통신 교환에서도 한글 이름이 그대로 가요. **통신(대전/교환)은 양쪽 모두 ko8이어야 해요** (ko7 이하와는 연결 안 됨)
- 펌웨어 크기 2.68MB / 3MB (글꼴 약 1MB)

## 사이트가 닫히면 (대처 방법)

웹 설치 페이지나 esptool-js 사이트가 없어져도 올릴 수 있어요:

1. **웹 설치 페이지를 내 PC에서 열기**: 이 저장소의 `TamaPoke/web/` 폴더에서
   `python -m http.server 8000` → Chrome에서 `http://localhost:8000` (Web Serial은 localhost에서도 돼요)
2. **Espressif Flash Download Tool** (Windows 프로그램, 인터넷 필요 없음): ESP32-S3 선택 →
   파일과 주소(위 표) 입력 → START
3. **esptool (파이썬)**: `pip install esptool` →
   `esptool --chip esp32s3 write-flash 0xe000 tamapoke-ko-v1.17-ko10.8-app-0xe000.bin`
4. **Arduino IDE**로 `TamaPoke/` 소스를 직접 올리기 (`TamaPoke/README_KO.md`의 설정 참고)
5. **SD카드에 파일 보내기**: SD카드를 빼서 PC에 꽂고 `mons` 폴더에 직접 복사하거나,
   `.bin` 파일(update.bin 등)은 `TamaPoke/tools/sdcard/mons/`에 두고
   `python TamaPoke/tools/send_sd.py --port COM5` (pyserial 필요)로 USB로 보내요
6. 켜지지 않을 때는 위 "복구" (파일 3개)

## 소리

SD카드 `mons` 폴더에 `bgm.wav`(평소), `battle_wild.wav`(배틀 중), `cry001.wav`~`cry151.wav`(울음소리).
형식은 **16kHz 모노 16비트 WAV**, 변환 방법은 `TamaPoke/README_KO.md`의 "SD카드 소리"를 보세요.

직접 구한 울음소리: 번호로 된 WAV 파일(`1.wav`, `025.wav`, `133 이브이.wav` …)이 있으면
`python TamaPoke/tools/prep_cries.py 받은폴더` → `sd_cries/mons/cry001.wav` …로 이름과 형식(16kHz 모노 16비트)을
맞춰 줘요 (Python만 있으면 돼요). 만들어진 `mons` 폴더를 SD카드에 복사하면 끝이에요.

최신 울음소리: `TamaPoke/tools/get_cries.py`를 실행하면 PokeAPI에서 1~151번의 최신 울음소리를 받아
`mons/cry001.wav`~`cry151.wav`로 변환해요 (Python + ffmpeg 필요). 게임 원본 음원(© Nintendo/Game Freak)이라
**개인용으로만** 쓰고 저장소에는 올리지 않아요.
