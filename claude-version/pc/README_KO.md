# 다마포케 PC 버전 (Windows, 개인 테스트용)

기기 펌웨어와 **같은 게임 코드**를 Windows에서 돌려요. 폰 앱(6판)과 같은 고화질 모드예요
(3배 해상도, 진짜 글꼴, 3D 움직이는 포켓몬).

## 실행
1. `TamaPoke.exe`를 원하는 폴더에 두고 더블클릭 (설치 없음)
   - "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]
   - 저장 데이터는 같은 폴더의 `TamaPoke_data\`에 생겨요 (지우면 처음부터)
2. 처음 한 번: 파일 고르기 창 → **mons.pak** 선택 (조각 `mons.pak.001 ~ .015`이면 모두 함께 선택)
3. 3D 그림: [메뉴] → [pak 파일 넣기] → `ani.pak.001`, `.002` 함께 선택 (추가만 돼요)

## 조작
- 마우스 왼쪽 = 손가락 (누르고 끌기 = 스와이프, 누르고 있기 = 길게 누르기)
- 아래 버튼: **[메뉴]** (pak 파일 넣기 / 그림: 3D·도트 / 닫기) · **[화면 끄기]** (기기의 PWR) · **[나가기]** (저장하고 닫기)
- Esc = [메뉴]. 창 크기는 자유롭게 (비율 유지)

## 기기와 다른 점
- 시간 = PC 시계. 꺼 둔 동안은 기기를 꺼 둔 것처럼 계산
- 없는 것: 통신 대전·교환, WiFi, 걸음·기울기 센서, 진동
- 배터리 표시 = 노트북 배터리 (데스크톱은 100%)

## 만들기 (리눅스에서 교차 컴파일)
```
pc/build_win.sh     # -> pc/build/TamaPoke.exe  (mingw-w64, arduino-cli 필요)
```
`host_win.cpp` = 게임 쪽 (android/jni/host_core.inc 공유), `win_main.cpp` = 창·마우스·파일 고르기 (windows.h),
`audio_win.cpp` + `audio_wave.cpp` = 소리 (waveOut). windows.h는 펌웨어 이름(CX, CY, INPUT...)과 겹쳐서 따로 둬요.
