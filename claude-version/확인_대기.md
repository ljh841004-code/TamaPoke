## 기기 확인 대기

- **다음 펌(ko12.6)에 반영됨, 아직 빌드 안 함: PP 늘림**
  - 모든 기술 PP 2배 (예: 파괴광선·하이드로펌프 5 → 10, 몸통박치기 35 → 70). 상대도 같음
  - 지면 각 기술 PP가 최소 절반까지 차 있음 (센터는 완전 회복)
  - 기존 세이브의 PP는 그대로 두고 최대치만 늘어남 → 이겨서 채우거나 센터에서 채우면 됨

- **ko12.5.1 (2026-10-04 빌드) 챔피언전 난이도 낮춤** — 확인: 이제 깰 수 있는지
  - 챔피언 레벨: 내 레벨 +2~+6 → **+0~+4**
  - 상대 1마리를 쓰러뜨리면 싸우던 포켓몬 **최대 체력 20%** 회복 (체육관·챔피언·오늘의 대전. 전엔 오늘의 대전만, 남은 체력의 35%)
  - 교체해서 쉬는 포켓몬은 턴마다 **최대 체력 5%**씩, **50%까지** 회복 (체육관·챔피언·오늘의 대전)
  - "숨을 고르고 있다" → "반동 때문에 움직일 수 없다!" (파괴광선·기가임팩트 등 강한 기술 다음 턴)

- **ko12.5.1 (2026-10-04 빌드) 작별/진화 질문 창** — 확인: 좌우 버튼, 계속 함께 뒤 24시간
  - [계속 함께]를 누르면 작별 버튼(문장)이 사라지고 24시간 뒤에 다시 물어봄. 원래도 24시간이었지만 **저장이 안 돼서** 껐다 켜면 바로 다시 나왔음 → 저장하도록 수정 ([형태 유지]도 같이)
  - 선택 버튼 두 개를 위아래로 붙어 있던 것에서 **좌우 큰 사각형 두 개**(사이 46px 간격)로. 사각형 밖이나 사이를 누르면 아무것도 안 고름 (진화 질문도 같은 모양)

- **ko12.5 (2026-10-04 빌드) 다마고치 2차** — 확인: 떼쓰기 빈도(너무 잦거나 드물지 않은지), 일과 알림, 성격 표시, 흔들 때 걸음 안 오르는지

  - 훈육: 필요한 게 없는데 가끔 떼씀(빨간 ! + "떼쓰는 중!", 15분) → 포켓몬 누르기 → [혼내기] 훈육 +20·기분 -5 / [달래기] 기분 +5·훈육 -8 / 무시 훈육 -3.

  - 성격: 돌본 방식(누적 30번 이상)으로 먹보/장난꾸러기/응석쟁이/노력파/깔끔이/의젓함(훈육 80+) → 작은 효과. 리본 추억에도 표시
  - 상태 카드 마지막 쪽 "생활": 성격·훈육 막대·오늘의 일과·연속 기록
- **(ko12.5에 포함) 걸음·배경 수정** (사용자: 흔들어 깨우기 OK, 그런데 흔들 때 걸음이 4 올라감)
  - 걸음: 흔들기(강한 움직임) 뒤 1.5초는 안 셈 + 걸음은 잠깐 모아 두었다가 조용히 끝났을 때(1.5초) 또는 16걸음 넘게 이어질 때 더함 → 흔들면 모아 둔 걸음은 버림
  - 걸음 표시: 알약 → 목표(5,000)까지 차오르는 링(초록, 5천 넘으면 금색, 1만 넘으면 무지개) + 아래 숫자(3,214). 위치는 시계 왼쪽(둥근 화면 안쪽, ◀와 안 겹침).
