2026-10-03 정리: 확인이 끝났거나 이미 고친 항목(ko8 ~ ko11.31)은 지웠어요. 버전마다 바뀐 점은 `버전기록.md`에 있고,
예전 확인 기록 전문은 git 기록(커밋 "Release v1.17-ko11.32" 시점의 이 파일)에서 볼 수 있어요.

## 기기 확인 대기

- **[다음 펌 준비 — 코드 반영됨, 아직 빌드 안 함] 세이브 백업 버그 (ko11.31부터)**: 기기 로그 `BAK: tpdex no cabe`.
  도감의 배운 기술 기록 "lrn"(6KB)이 백업용 4KB 버퍼에 안 들어가 **백업 전체가 취소**되고 있었음 → 실제 크기만큼 PSRAM에 잡도록 수정 (savebak_sd.cpp addEntry)
- **기기 PERF 로그 분석 (2026-10-04, ko12.0)** — 다음 최적화의 기준
  - 전투 화면 한 장 그리기: 평균 **88~92ms** (약 11장/초), 최대 95~127ms, **모든 장이 50ms 넘음** (이펙트 없는 때도 87ms)
    → 렉의 주원인은 SD가 아니라 **전투 화면 그리기 자체**. 다음 단계: PC에서 부분별 시간 측정(하늘·지형·포켓몬·상자·전송) 후
    움직이지 않는 하늘·지형을 미리 그려 두고 복사(지금은 이펙트 중에만), 다시 그릴 필요 없는 부분 줄이기
  - 전투 준비(PERF setup): 309~438ms (스프라이트 300~530KB 읽기) — 견딜 만함
  - 이펙트 읽기(PERF fx): 대부분 0.1~1초, 큰 것(460~600KB)은 2~8초 (음악 우선이라 천천히 읽음, 화면은 안 멈춤)
  - 메모리: heap 135KB, 최저 99KB — 여유 있음

- **ko12.0 (2026-10-04 빌드)**: 정리판. 기능은 ko11.32와 같음 → 아래 점검 목록으로 한 바퀴
  (부팅·기본 화면·먹이/놀이·훈련 3종+배구·야생 전투·체육관/리그·도감·보관함/명예의 전당·스토리·원정·센터·소리·배경음 고르기·세이브 백업·다시 켠 뒤 세이브 유지)

- **ko11.32 + 가벼운 SD 이펙트** (`TamaPoke_SD_fx_ko11.31.5.zip`): 전투 중 렉이 줄었는지 (스토리 챔피언전 포함)
  - 그래도 렉이 있으면 USB 시리얼의 `PERF bat` / `PERF setup` / `PERF fx` 로그를 받아 가장 느린 곳부터 고치기
    (후보: SD 파일 묶음(pak), 화면 그리기 줄이기)
- **애니 스토리 1~13화**: 전투 배경음이 야생 전투 음악(battle_wild.wav)인지, 14화부터 스토리 전투 음악인지
- **난이도**: 사용자 테스트 중 (지금은 적당하다고 함)

## 보류 (요청이 있을 때 작업)

- **6대6 파티 전투**: 다음 큰 업데이트 때 자세히 알아보기로 함
