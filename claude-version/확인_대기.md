# 확인 대기 (사용자 테스트 중)

2026-10-03 정리: 확인이 끝났거나 이미 고친 항목(ko8 ~ ko11.31)은 지웠어요. 버전마다 바뀐 점은 `버전기록.md`에 있고,
예전 확인 기록 전문은 git 기록(커밋 "Release v1.17-ko11.32" 시점의 이 파일)에서 볼 수 있어요.

## 기기 확인 대기

- **ko12.3.2 (2026-10-04 빌드) 도감 첫 기술 깜박임 (3차)** — 사용자: 많이 줄었음, 몇몇 포켓몬은 처음에 아직 깜박임. 버튼 둘레 점은 불편하지 않음
  - 남은 후보: 배경음·울음소리·스프라이트 SD 읽기(이펙트 말고), 또는 SD 읽기 때 전류가 튀어 화면 밝기가 흔들림 → USB 연결/배터리만일 때 차이, 깜박이는 포켓몬 번호 + 로그 받기 — ko12.3.1 로그 결과:
  - 사용자: 상세에 들어가 처음 누르는 기술 대부분이 **화면 전체** 깜박임, 그 뒤로는 안 깜박임
  - 로그: 깜박인 첫 사용은 모두 원작 이펙트(sd=1)였음 → 도트 이펙트 탓 아님. 차이는 **SD에서 이펙트를 읽는 중이었는지**뿐
    (처음: ready=0, 다 읽히자마자 시작 + 나머지 파일 계속 읽기 / 나중: ready=1, 읽는 것 없음). 화면 한 장 71~79ms(이펙트 큰 것 105~113ms)는 처음·나중 같음
  - 추정: SD → PSRAM 읽기와 화면 전송이 겹칠 때 화면이 흔들림 (기기에서만 생김, PC로는 재현 불가)
  - 수정: 누른 기술은 **이 포켓몬의 이펙트 파일 읽기가 모두 끝난 뒤** 시작 (= 나중에 누를 때와 같은 상태). 최대 6초, 읽는 중엔 버튼 둘레 점
- **ko12.3.1 (2026-10-04 빌드) 도감 첫 기술 깜박임 (2차)** — 로그(DEX tap, PERF dexfx, PERF dexframe) + 깜박임 모습(언제/어디) 받기 (사용자: ko12.3에서도 한 번은 깜박임)
  - 추정 원인: 기다리는 시간 1.5초가 짧음. 배경음이 SD를 먼저 쓰고, 다른 기술 파일을 읽던 중이면 그걸 끝낸 뒤라 큰 이펙트는 2~4초 걸림 → 1.5초 넘으면 도트 이펙트로 넘어감
  - 수정: 최대 6초 기다림 + 기다리는 동안 버튼 둘레에 도는 점(읽는 중 표시) (화면 검사 13e). USB 로그 `PERF dexfx <기술> wait=<ms> sd=<1/0>` — sd=0이면 아직 도트로 나간 것
  - 그래도 깜박이면: 누르는 순간/이펙트 중간/끝 중 언제인지, 화면 전체인지 포켓몬만인지 받기
  - **ko12.3 로그 (2026-10-04)**: 이펙트 읽기 89~1389ms로 모두 1.5초 안 → "기다림 부족"만으로는 설명이 안 됨 (원인 아직 모름)
    → 진단 로그 추가: `DEX tap mv= ready= queued=` (누른 순간 파일 상태), `PERF dexframe <ms> fx= t= sd= pend=` (70ms 넘게 걸린 장)

- **ko12.3 (2026-10-04 빌드)**: 확인할 것
  - 도감 상세: 기술 버튼 속성 그림, 처음 쓰는 기술에서 깜박임 없는지 (읽는 중이면 조금 늦게 원작 이펙트)
  - 무지개구슬: 합성에서 나오면 모습·이름 "○○ 무지개구슬"·"공격/방어 +N%", 장착 후 전투에서 공격·방어 둘 다 오르는지
  - (참고) 독이 다음 포켓몬에게 넘어가는지: PC 검사로 넘어가지 않음 확인 — 상대가 독 기술을 또 쓴 것

- **ko12.2 (2026-10-04 빌드)**: 확인할 것

  - 자동 잠: 기본 화면 3분 가만히 → 잠듦, 한 번 누르면 깸, 자다가 배고프면(배부름 30) 스스로 깸, 배고프거나 더러우면 안 잠

- **ko12.1 (2026-10-04 빌드)**: 전투 중 화면 전송을 코어 0 태스크로 (이중 버퍼). **기기 PERF 결과 (2026-10-04)**:
  - 전투 한 장: 평균 **88~92ms → 40~55ms** (약 2배, 11 → 20~25장/초). `wait=0ms` = 전송 시간이 완전히 숨겨짐
  - 이펙트 없는 때 40~41ms, **SD 이펙트가 나오는 장은 최대 85~96ms** (남은 렉은 이펙트 그리기) → 다음 최적화 대상
  - 이펙트 읽기도 빨라짐 (460KB: 2~6초 → 0.7~1.5초). 전투 준비 240~440ms (1.2MB 롱스톤 그림만 1.2초)
  - 아직 받을 것: 깜박임·화면 섞임 없는지 사용자 확인
  - PC 측정(test/render/perf.sh, ko12.0): 전투 한 장 0.43ms (기기는 90ms → CPU보다 메모리·전송이 큰 몫). 부분 비율: 배경 28~31%, 포켓몬 16~17%, 상자 14~17%, 메뉴 13~17%

- **ko12.0.1: 세이브 백업 버그 — 확인됨("백업했어요!") (ko11.31부터)** — 확인: [지금 백업] 후 "백업했어요!", 로그에 `BAK: tpdex no cabe`가 더는 안 나오는지: 기기 로그 `BAK: tpdex no cabe`.
