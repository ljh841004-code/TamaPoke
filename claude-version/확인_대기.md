## ko11.5 — 데이터가 쌓인 뒤의 동작 (2026-09-27)
- 상황: 세이브 데이터 때문으로 보이는 부팅 반복(USB 연결/끊김, 화면 안 켜짐) → 0x0 전체 설치로 초기화 후 복구.
  ko11.5에서 빠른 연타 렉은 **현재 없음** (새 게임 상태).
- 사용자가 새 게임으로 데이터를 쌓아 가며 확인 중. 결과를 알려 주면 이어서 대응.
- 확인할 것
  - 훈련(공격·공놀이) 빠른 연타 렉: 결과 화면 "그리기 최대 / 멈춤 최대" 숫자
  - 부팅 반복이 다시 생기는지. 생기면 화면의 `last stop: N 단계` + 원인(CRASH/BROWNOUT) 사진을 받기
    - save:* 단계면 세이브 읽기 쪽 (pet/box/hall/fame/dex) 추가 검사
    - first frame / running 이면 첫 화면 그리기 (스프라이트·박스 데이터)
  - 보관함·명예의 전당·도감이 많이 찼을 때(NVS 용량) 저장/부팅
- 이후 정리: 원인이 좁혀지면 결과 화면의 측정 표시는 뺄 것

## ko11.9.1 (2026-09-28 빌드, 기기 확인 대기)
- 사용자: 배구가 너무 어려움. 화면이 손가락 하나만 인식 → 띠로 이동하면서 점프/스파이크 불가
  → 이동 자동(포켓몬이 공 떨어질 곳으로 감), 어디든 톡 = 점프, **점프 중 공에 닿으면 자동 스파이크** (두 번째 톡 필요 없음)
  → 상대 약하게: 반응 380ms(5단계 100ms), 스파이크 5~50%, 받기 20~70%, 속도 낮춤. 내 받기 60~80%
  → PC 시뮬(가상 플레이어): 0~1단계 거의 승리, 3단계 50~70%, 5단계 7~17%. 한 경기 1~2분
- 사용자: 전투 때 2세대(152~251) 이름 색 다르게 → 체력 칸 이름을 진한 금색 (screenshots 08c)

## ko11.9 배구 미니게임 (시험판 — 사용자가 써 보고 개선 또는 폐기 결정)
- 훈련 메뉴 5번째 줄 "배구: 5점 먼저 내기" (최고 N연승). 상대 = 무작위 포켓몬(전설·내 종 제외), 나 = 키우는 포켓몬
- 조작: 아래 띠를 누른 채 밀어서 이동, 위를 톡 = 점프, 공중에서 톡 = 스파이크. 점수 칸 2초 = 그만
- 스탯: 스피드→이동, 공격→스파이크 속도, 방어→몸 크기·스파이크 받기(50~70%)
- 연승할수록 상대가 강해짐(0~5단계). 승리: 연승+1, 신기록이면 경험치·사탕, 아니면 사탕 1. 스피드 훈련 효과
- PC 시뮬레이션(따라 하는 봇 상대): 한 경기 약 40~60초, 상대 단계 0→5 승률 0%→100%

## ko11.8 (2026-09-27 빌드, 기기 확인 대기)
- **배경음 고르기**: 소리 설정 → [배경음 고르기 >]. SD카드 bgm.wav, bgm2.wav … bgm8.wav 중 켠 곡만 무작위
  (같은 곡 연달아 안 나옴, 켠 곡이 하나면 그 곡만 반복). ▶ = 바로 듣기. 설정 "bgmMask"는 새로 시작해도 유지
  - 곡 이름: WAV 안의 제목(INAM). `prep_music.py 곡.mp3 bgm3.wav --title "Route 1"`. 없으면 "N번 곡"
  - bgm2.wav(Pallet Town)는 제목 넣은 파일로 다시 만들어 둠 (원하면 SD에 교체). bgm.wav(Inst.wav)는 원곡 이름 모름
- **따라오기 팝업**: 야생 승리 20% "○○가 따라오고 싶어 해요! 데려갈까요?" [데려가기]/[보내주기]
  (예전: 자동으로 보관함). 이미 있는 포켓몬이면 데려가기 → 보관함/사탕 선택. 20초 안 고르면 데려가기(예전처럼)
- **전투 중 똥 안 쌈**: 야생·체육관·리그·오늘의 도전·통신 대전 화면에 있는 동안은 똥이 안 생김
- **보관함 화면**: 왼쪽 ◀ = 나가기 (상세 화면에서는 목록으로). 보관함·왕관 탭을 조금 내리고 폭을 줄여 둥근 화면 안으로 (y34→44, 폭 150→132). 목록 5마리 그대로
- **방어 후 반격**: 방어한 턴에 상대 공격이 맞으면 자동 반격 "○○의 반격!" (몸통박치기 절반 위력, 반드시 맞음, 급소 없음, 고스트는 효과 없음).
  나와 상대 모두 같은 규칙 (상대는 체력 30% 미만일 때 25%만 방어). 통신 형식 4→5: **통신 대전·교환은 양쪽 모두 ko11.8**
- 정리할 것: 훈련 결과 화면의 측정 표시(그리기/멈춤) — 렉이 다시 안 생기면 뺄 예정
