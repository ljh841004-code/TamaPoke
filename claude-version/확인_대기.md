    - save:* 단계면 세이브 읽기 쪽 (pet/box/hall/fame/dex) 추가 검사
    - first frame / running 이면 첫 화면 그리기 (스프라이트·박스 데이터)
  - 보관함·명예의 전당·도감이 많이 찼을 때(NVS 용량) 저장/부팅

## ko11.8 (2026-09-27 빌드, 기기 확인 대기)
- **배경음 고르기**: 소리 설정 → [배경음 고르기 >]. SD카드 bgm.wav, bgm2.wav … bgm8.wav 중 켠 곡만 무작위
  (같은 곡 연달아 안 나옴, 켠 곡이 하나면 그 곡만 반복). ▶ = 바로 듣기. 설정 "bgmMask"는 새로 시작해도 유지
  - 곡 이름: WAV 안의 제목(INAM). `prep_music.py 곡.mp3 bgm3.wav --title "Route 1"`. 없으면 "N번 곡"
  - bgm2.wav(Pallet Town)는 제목 넣은 파일로 다시 만들어 둠 (원하면 SD에 교체). bgm.wav(Inst.wav)는 원곡 이름 모름
- **따라오기 팝업**: 야생 승리 20% "○○가 따라오고 싶어 해요! 데려갈까요?" [데려가기]/[보내주기]
  (예전: 자동으로 보관함). 이미 있는 포켓몬이면 데려가기 → 보관함/사탕 선택. 20초 안 고르면 데려가기(예전처럼)
- **전투 중 똥 안 쌈**: 야생·체육관·리그·오늘의 도전·통신 대전 화면에 있는 동안은 똥이 안 생김
- **보관함 화면**: 왼쪽 ◀ = 나가기 (상세 화면에서는 목록으로). 보관함·왕관 탭을 조금 내리고 폭을 줄여 둥근 화면 안으로 (y34→44, 폭 150→132). 목록 5마리 그대로
- **방어 후 반격**: 방어한 턴에 상대 공격이 맞으면 자동 반격 "○○의 반격!" (몸통박치기 절반 위력, 반드시 맞음, 급소 없음, 고스트는 효과 없음).
  나와 상대 모두 같은 규칙 (상대는 체력 30% 미만일 때 25%만 방어). 통신 형식 4→5: **통신 대전·교환은 양쪽 모두 ko11.8**
- 정리할 것: 훈련 결과 화면의 측정 표시(그리기/멈춤) — 렉이 다시 안 생기면 뺄 예정
