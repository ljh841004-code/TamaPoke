TamaPoke KO  v1.17-ko6.2  정리 (클로드 버전)
========================================
보드: Waveshare ESP32-S3-Touch-AMOLED-1.75
바탕: socquique/TamaPoke v1.17 + 기능 추가


[추가된 기능]
- 한국어 기본 : 처음 켜면 한국어 (시간 화면에서 언어 변경 가능)
- WiFi 시간 자동 맞춤 : 켤 때 + 하루 한 번 NTP 동기화 (기본 UTC+9)
                        끝나면 WiFi 자동 꺼짐 (배터리 절약)
- 야생 배틀 : 턴제 / 몸통박치기, 타입 기술, 방어, 도망 / 1세대 타입 상성
- 통신 대전 (2인) : 두 대를 ESP-NOW로 연결해 자동 대전 (공유기 필요 없음)
- 통신 교환 (2인) : 포켓몬 교환
                    윤겔라, 근육몬, 데구리, 고우스트는 교환하면 진화
- SD카드 소리 (ko2) : 배경음, 배틀 배경음, 포켓몬 울음소리
- ko4 : 큰 시계, 보관함, 도감 기록, 소리 설정, 훈련 3종, 실시간 저장,
        배틀 아이템(물약/포켓볼), 검정 글자 + 깔끔한 한글, 게이지 숫자

[SD카드에 파일 넣기] (울음소리, 배경음, update.bin)
1. 보드는 평소 화면, USB로 PC에 연결 (esptool 창은 닫기)
2. https://socquique.github.io/TamaPoke/web/ -> 2단계 [Connect board]
   ([Load sprites]는 누르지 않기)
3. "pick them manually" -> 파일 형식 "모든 파일" -> 파일 선택
   -> SD카드 mons 폴더에 저장됨


[ko5 새 기능]
- SD카드 업데이트 : 웹 설치 페이지로 update.bin을 보냄 (mons 폴더)
                    -> 네트워크 화면 [SD 업데이트] -> [업데이트] -> 자동 재시작
- 보관함 규칙     : 포켓볼로 잡으면 항상 / 이기면 20% 확률로 동료가 됨
- 도감            : 두 번 탭하면 나가기
- 배경음          : 전원 버튼 짧게 눌러 화면 끄면 배경음 멈춤 (켜면 이어서)
- 울음소리        : tools/get_cries.py 로 최신 울음소리 (개인용)
- esptool 업데이트는 이제 주소 0xe000 + ...-app-0xe000.bin 파일


[ko4 새 기능 요약]
- 큰 시계  : 기본 화면 하늘에 현재 시간 (HH:MM)
- 게이지   : 포만/기분/기력/청결 막대 안에 0~100 숫자
- 보관함   : 배틀 페이지 -> [보관함]. 잡은 포켓몬 + 이기면 20% (최대 60)
             최종 진화 후 작별하면 다음 포켓몬이 보관함에서 무작위로 나옴
             (보관함이 비었거나, 도망/놓아주기로 끝나면 알)
- 도감     : 옆으로 스와이프. 만난 포켓몬은 색으로, 탭하면 상세 정보
- 배틀     : 몸통박치기 / 타입기술 / 방어 / 물약 / 볼 / 도망
             물약 = 체력 절반 회복, 볼 = 포획 (체력 낮을수록 잘 잡힘)
             이기면 포켓볼 +2, 물약 +2 / 져도, 도망쳐도 불이익 없음
             시작 아이템: 포켓볼 5, 물약 2
- 훈련     : 포켓볼 버튼 또는 배틀 페이지 [훈련]
             공격 = 10초 연타 / 방어 = 떨어지는 볼 터치 (20초)
             속도 = 좌우에 잠깐 나오는 볼 터치 (15라운드) / 공놀이 = 기분만
- 소리 설정 : 아래로 스와이프 -> [소리] -> 배경음 / 포켓몬 목소리 / 시스템음
- 저장     : 1분마다 + 행동마다 + 전원 버튼 누를 때 (길게 눌러 끌 때도 저장)


[화면 조작]
- 아래로 스와이프 : 시간 설정 화면 (소리, WiFi, 언어)
- 위로 스와이프   : 스탯 카드 (옆으로 넘기면 배틀 / 메달 / 진행도)


[WiFi 시간 맞추기]
1. 아래로 스와이프 -> 가운데 [WiFi] 버튼
2. [WiFi 설정하기] -> 휴대폰으로 TamaPoke-XXXX WiFi 연결
   (비밀번호: tamapoke)
3. 설정 페이지가 뜨면 집 WiFi 이름, 비밀번호, 시간대 입력 -> 저장
   (안 뜨면 브라우저에서 192.168.4.1)
4. 이후 자동으로 시간 맞춤
* 2.4GHz WiFi만 됨


[야생 배틀]
- 위로 스와이프 -> 배틀 페이지 -> [야생 배틀]
- 또는 메인 화면의 초록 버튼 "! 야생 포켓몬 출현 !" 탭 (5분 뒤 사라짐)
- 이기면: 공격/방어/속도 상승 + 기분, 유대감 증가
- 싸우면: 기력, 포만감 조금 감소
- 못 싸우는 경우: 기력 15 미만, 알 상태, 자는 중


[통신 2인]
- 두 기기 모두: 배틀 페이지 -> [통신 2인] -> 같은 메뉴 선택 (대전 또는 교환)
- 가까이 두면 자동 연결 (몇 m 이내)
- 대전: 두 화면에 같은 배틀이 나옴. 이기면 전적 + 훈련치 상승
- 교환: 상대 포켓몬 확인 후 [예] -> 둘 다 수락하면 교환
        ※ 지금 키우는 포켓몬이 넘어가니 주의!
        받은 포켓몬은 도감에 등록됨


[SD카드 소리] (ko2)
SD카드 /mons/ 폴더에 넣으면 자동 적용
  bgm.wav                 평소 배경음 (반복)
  battle_wild.wav         야생 배틀, 통신 대전 중 (결과 화면부터 평소 배경음)
  cry001.wav ~ cry151.wav 울음소리 (켤 때, 쓰다듬을 때, 종이 바뀔 때,
                          배틀 상대가 나올 때) / 번호 = 도감 번호 3자리
형식: WAV, 16kHz, 모노, 16비트 PCM (울음소리는 30초 이하)
변환: ffmpeg -i 원본.mp3 -ac 1 -ar 16000 -c:a pcm_s16le -map_metadata -1
      -fflags +bitexact -flags:a +bitexact cry025.wav
      (뒤쪽 옵션을 빼면 울음소리가 안 나옴)
없는 파일은 건너뛰고 기본 효과음은 그대로 나옴


[시리얼 명령] (115200bps, 디버깅용)
WIFI 이름|비번   WiFi 설정
WIFIOFF          WiFi 끄기
NTP              지금 시간 맞추기
TZ 540           시간대 (분 단위, 540 = 한국)
NET              네트워크 상태
WILD             바로 야생 배틀
ALERT            야생 출현 알림 띄우기
VOL 25 65 100    볼륨 (배경 울음 효과, 각 0~100) / VOL만 치면 현재 값
(원본 명령 STATS, HATCH, LVL 16 등도 동작)


[주의]
- 스프라이트는 SD카드에 있어야 함 (원본 웹 설치 페이지의 Load sprites)
- 업데이트: SD카드(update.bin) 또는 esptool 주소 0xe000 (포켓몬 유지)
- esptool 업데이트 파일은 반드시 주소 0xe000 (0x10000이나 0x0에 올리면 안 켜짐)
- ko3~ko5.1 -> ko6 으로 올릴 때만 PowerShell 1200bps 명령이 필요
- 실기기 테스트 전 버전: WiFi 포털, ESP-NOW 통신, 한국어 폰트 크기는
  문제 생기면 시리얼 로그(NET, LINK ...)로 확인
